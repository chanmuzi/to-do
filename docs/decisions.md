# 결정 기록

명세(`docs/spec/`)에 없거나 명세를 바꾼 결정을 적는다. 최신 항목을 위에 둔다.
결정이 바뀌면 옛 항목을 지우지 않고 상태를 `대체됨`으로 바꾼 뒤 새 항목을 추가한다.

상태: `현행` 따르는 결정 · `임시` 사용자 확인 전 임시 값 · `미정` 정해야 하는 것 · `대체됨` 더 이상 따르지 않음

| D-019 | 2026-11-16 | 임시 | 편집기에서 명세가 정하지 않은 동작. 목록 기호(`- `, `[ ] `, `> `)와 들여쓰기는 커서가 있는 줄에서도 글자로 보이지 않고 왼쪽 칸의 그림이 대신한다. 글자 시작에서 ⌫를 누르면 기호가 지워지고, 들여 쓴 본문은 한 단계 나온다. 커서 줄에서 보이는 것은 인라인 기호, 제목의 `#`, 코드 블록의 ``` 줄이다. 여러 줄을 선택하면 걸친 줄 모두에서 보이고, 편집기에 포커스가 없거나 창이 키 창이 아니면 어디에도 보이지 않는다. 링크는 그냥 누르면 열린다. 형광펜 단축키는 노랑, 회색, 로즈, 블루 다음에 형광펜을 지운다. ``` 를 치고 Return 하면 닫는 줄을 함께 넣는다. 선택 바탕색은 `hover`를 쓴다. 복사할 때 HTML의 형광펜 색은 라이트 값이고 투두는 `<input type="checkbox">`로 나간다 | spec 06, 13, D-009 |
