## 임시 값으로 진행 중인 것

`docs/spec/20-open-questions.md`의 1~8번, 11~13번은 사용자 확인 전이다(1~3번은 D-017, 4번과 8번은 D-014에 옮겨 적음). 해당 영역을 구현할 때 괄호 안의 임시 값을 쓰고, 이 표에 항목으로 옮겨 적는다.
