# 시안 페이지 만드는 법

AGENTS.md 기본 규칙 10의 시안(고를 수 있는 한 페이지)을 만들 때 읽는다. 모양은 `docs/mockup-kit/`의 키트로 통일한다. 페이지마다 CSS를 새로 짓지 않는다.

## 왜 키트를 쓰나

2026-11-26 "본문 색과 밑줄" 시안은 이전 시안(일정 창과 블록 편집)의 부품을 쓰지 않고 새로 지었다가 사용자가 "이전 것이 보기 더 좋았다"고 했다. 그 페이지에서 생긴 일:
- 노트 그림을 작은 카드 세 개에 줄여 넣어 앱 크기 감이 사라졌다.
- 줄을 `display:flex`로 만들어 서식 넣은 글 사이 공백이 사라졌다(`1on1미루지`).
- 체크박스와 글머리가 빠지고, 노트가 카드 가장자리에서 잘렸다.
- 선택지 설명이 그림보다 길었다.

## 만드는 순서

1. 본문 파일 하나를 scratchpad에 쓴다. `docs/mockup-kit/template.html`을 복사해 시작한다. 맨 위에 `<title>`.
2. `docs/mockup-kit/build.sh <본문.html> <page.html>`로 키트를 합친다. 금지 기호가 있으면 실패한다.
3. 헤드리스 Chrome으로 한 번 찍어 본다(아래 "확인"). 고칠 것을 한 번에 고친 뒤 Artifact로 올린다.

## 모양 규칙

- **그림은 앱 크기 그대로.** 노트는 `FloatKit.note()`로 그린다(340pt 폭, 머리 줄 36, 본문 14/24, 들여쓰기 21). `.app`이 1.5배로 키운다. 그림을 줄이려고 폭이나 글자 크기를 바꾸지 않는다.
- **카드는 한 줄에 둘까지.** `.picks`가 화면 폭에 따라 하나나 둘로 놓는다. 셋 이상을 한 줄에 놓지 않는다. 선택지가 넷 이상이면 둘씩 줄을 바꾼다.
- **한 그림에서 바꿔 보는 것이 나으면 무대 하나와 전환.** 여러 선택지가 같은 장면의 작은 차이라면 `.stagebox` 하나에 그리고 `.seg`(지금/바꾼 것)나 체크로 바꿔 본다. 고르기는 그 아래 카드에서.
- **바뀌는 값은 표로 먼저.** 치수, 색, 시간이 바뀌면 `.tbl`에 항목, 지금(`.old`), 새 값, 근거.
- **눌러 볼 수 있으면 눌러 보게.** 움직임, 호버, 키 입력, 순서가 핵심이면 실제처럼 동작하게 만든다(재생 버튼, "느리게" 체크, 직접 쓰는 노트). 정지 그림 여러 장으로 대신하지 않는다.
- **설명은 짧게.** 선택지 설명은 두 문장 안: 무엇이 다른지와 그 대가. 근거와 참고는 절 설명이나 "참고한 것"에.
- **기존 부품만.** 노트(`.note`, `.blk`, `.cb`, `.bu`, `.cv`), 인라인 서식(`.hl`, `.lk`, `.ul`, `.dt`, `code`), 메뉴(`.menu .row`, `.sep`), 색 칸 줄(`.swr`), 서식 막대(`.fbar`). 새 요소가 꼭 필요하면 시안에서 "새 요소"라고 표시하고(AGENTS.md 규칙 10), 쓸 만하면 키트에 더한다.
- **글자는 `.tx` 안에 인라인으로.** 서식은 `html`에 span으로 넣는다. 줄 안을 flex로 나누지 않는다.
- **다크.** 맨 위 "노트 그림을 다크로" 체크로 `.app.dk`를 켠다. 노트 색은 `--n-*`만 쓴다. 새 색은 `App/Resources/tokens.json`의 라이트와 다크 값을 함께 옮긴다.
- 페이지 구조, 답 복사, 메모, 추천 표시는 AGENTS.md 규칙 10과 같다. `FloatKit.answers()`가 맨 아래 답 복사와 고른 값 저장을 맡는다. 저장 키는 시안마다 새로(`float-<주제>-pick-1`).

## 확인

한 번만 찍는다.

```sh
S=<scratchpad>/<주제>
{ echo '<!doctype html><meta charset="utf-8">'; cat $S/page.html; } > $S/shot.html
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --disable-gpu --hide-scrollbars \
  --window-size=1200,2400 --screenshot=$S/shot.png file://$S/shot.html
```

볼 것: 체크박스와 글머리가 보이는지, 글 사이 공백, 노트가 잘리지 않는지, 카드가 한 줄에 둘 이하인지, 다크 체크를 켰을 때 글이 읽히는지.
