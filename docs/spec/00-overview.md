# 플로팅 노트 구현 명세

B v8 최종 시안(`design.html`)을 macOS 네이티브 앱(SwiftUI + AppKit)으로 옮기기 위한 명세입니다.
값은 모두 `tokens.json`의 토큰 이름으로 적었습니다. 토큰 값 자체는 3장의 표와 `tokens.json`에 있습니다.

## 0. 읽는 법

- 모양이 궁금하면 `design.html`을 브라우저로 열거나 `screens/`의 캡처를 봅니다. 화면 번호(화면 1부터 9)는 세 곳에서 같습니다.
- 이 문서와 시안이 다르면 **이 문서가 우선**입니다. 시안은 Linux의 Chrome에서만 확인했고, 글꼴 굵기와 흐림 효과는 macOS에서 다르게 보일 수 있습니다.
- "가정"이라고 표시한 것은 시안에서 정하지 않고 제가 채운 값입니다. 20장에 모아 뒀습니다. 그 부분을 구현하기 전에 사용자에게 확인하세요.
- 앱 이름 "플로팅 노트"는 가칭입니다.

## 1. 개요

작고 가벼운 메모 창 여러 개를 화면 위에 항상 띄워 두는 개인용 메모, 투두 앱입니다. 사용자는 개발자이고, 코드 에디터나 브라우저 위에 노트를 띄워 둔 채 일합니다.

| 구성 | 한 줄 설명 | 화면 |
| --- | --- | --- |
| 플로팅 노트 창 | 떠 있는 작은 창. 편집 중에 바로 스타일이 입혀지는 마크다운 | 1, 2 |
| 빠른 캡처 바 | 전역 단축키로 뜨는 한 줄 입력 | 3 |
| 라이브러리 | 전체 노트 목록과 정리 | 4 |
| 스페이스 아이콘 고르기 | 기호, 이모지, 이미지 | 4 |
| AI 패널 | 에이전트와 대화해 투두 후보를 받음 | 5 |
| 테마 설정 | 색, 글꼴, 투명도, 표시 방식 | 6 |
| 단축키 표 | 단축키를 보는 유일한 곳 | 7 |
| 메뉴 막대 아이콘과 메뉴 | 모든 창으로 가는 길 | 8 |
| 노트 찾기 | 다른 노트로 빠르게 가기 | 9 |

나중으로 미룬 것(이번 범위 아님): 픽셀 캐릭터 형태의 AI 에이전트, 스페이스 색을 그 스페이스 새 노트의 기본 색으로 쓰기.
