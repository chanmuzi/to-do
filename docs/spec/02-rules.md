## 2. 반드시 지킬 규칙

사용자가 시안을 보며 하나씩 정한 것들입니다. 구현 중에 판단이 필요하면 이 규칙을 먼저 따릅니다.

1. **흑백 위주.** 글자와 아이콘은 `text`, `text-2`, `text-3` 세 단계만 씁니다. 색은 노트 바탕(팔레트), 형광펜, 임박한 리마인더(`warn`), 인라인 코드의 글자(`code-accent`. 설정에서 무채색으로 바꿀 수 있음, D-035)과 예정 편집과 사이드바의 캘린더 색 표시(막대와 동그라미, D-088)에만 나옵니다.
2. **장식 기호 금지.** 가운뎃점 같은 구분용 기호를 화면에 쓰지 않습니다. 구분은 간격과 아이콘으로 합니다.
3. **불필요한 글자 금지.** 개수 요약, 상태 줄, 안내 문구를 넣지 않습니다. 빈 상태에도 안내 문장 대신 할 수 있는 동작 하나만 둡니다.
4. **단축키 안내는 단축키 표에만.** 버튼, 메뉴, 툴팁, 입력 칸 어디에도 단축키를 적지 않습니다. (macOS 메뉴의 기본 단축키 표시도 끕니다.)
5. **포커스는 창 모습을 바꾸지 않습니다.** 본문 포커스는 커서와 설정에 따른 서식 표시줄을 켭니다. 창 바탕, 테두리, 그림자, 투명도는 그대로입니다.
6. **호버와 포커스는 따로 동작합니다.** 상단 조작은 노트 호버에 반응합니다. 서식 버튼은 기본으로 숨기고, 모양 설정을 켠 노트에서 본문 편집 중에만 표시합니다.
7. **호버로 나타나는 것은 자리를 미리 차지합니다.** 나타나거나 사라질 때 다른 요소가 밀리거나 창 크기가 변하면 안 됩니다. 투명도와 색만 `dur` 동안 바뀝니다.
8. **즉시 바뀌는 것은 없습니다.** 나타남, 사라짐, 색 변화는 모두 `dur`(180ms), `ease` 전환입니다.
9. **마우스 모양을 바꾸지 않습니다.** 누를 수 있는 것 위에서도 화살표입니다. 글자를 쓰는 곳에서만 I자 커서입니다. 누를 수 있는 곳은 아래 역할에 맞게 바탕이나 글자색으로 반응합니다.
10. **아이콘 버튼에는 테두리가 없습니다.** 평소에는 아이콘만 보이고, 그 아이콘에 마우스를 올렸을 때만 `hover` 색 상자가 나타납니다.
11. **버튼과 선택 칸은 작고 조용하게.** 높이 `ctl-h`(24px). 고른 상태는 테두리 없는 따뜻한 회색 `selected`와 중간 굵기 `fw-selected`로 표시합니다. 켜진 노트 서식 버튼에는 더 옅은 `format-active`를 씁니다(D-184). 세그먼트는 예외로 회색 홈에서 고른 칸에 흰 바탕을 씁니다. 같은 계열의 옅은 `hover`는 고르지 않은 칸에 씁니다. 검정(`accent`) 채움이 남아 있는 곳은 체크된 체크박스, 켜진 스위치, 슬라이더, 입력 커서뿐입니다.
    라이브러리 목록의 묶음 머리는 macOS 메모의 목록 구조를 따른 예외로, 그림과 굵기 600의 이름을 함께 씁니다(D-176).
12. **노트 제목과 본문은 별개입니다.** 제목은 상단 줄의 별도 칸입니다. 본문 첫 줄이나 `#` 제목이 노트 제목이 되지 않습니다.
13. **리마인더는 한 번에 한 가지 정보만.** 시간, 남은 시간, 아이콘 가운데 설정에서 고른 하나만 보입니다.
14. **글꼴 역할.** 사람이 쓴 글과 버튼 글자는 Pretendard, 앱이 붙이는 정보(시간, 개수, 날짜)와 코드는 D2Coding입니다. 라이브러리의 시간과 개수, 일정 목록의 시간은 확정 시안에 따라 Pretendard와 같은 폭 숫자를 씁니다.
15. **입력 커서는 얇은 일반 커서**(`caret-w` 1.5px, `accent` 색)입니다. 블록 커서를 쓰지 않습니다. 본문, 제목, 캡처, 노트 찾기는 조합 범위와 확정을 유지하되 시스템 조합 밑줄과 자동 고침, 완성, 예측 장식을 끕니다. 노트 본문과 제목에서는 옅은 조합 밑줄을 선택할 수 있습니다(D-109).
16. **에이전트 로고는 설정에서만 씁니다.** 설정은 확정 타일과 이름을 함께 쓰고, 다른 화면은 이름으로 표시합니다(D-150).
17. **금지 기호의 범위.** U+00B7, U+2027, U+2219, U+22C5는 화면, 접근성 라벨, 코드, 테스트, 문서에 쓰지 않습니다. 나열은 쉼표나 와/과, 화면의 구분은 간격이나 줄 바꿈을 씁니다(U+2022 제외).

### 누를 수 있는 것의 모양

| 역할 | 평상시 | 올렸을 때 | 예 |
| --- | --- | --- | --- |
| 아이콘 버튼 | text-2 아이콘 | hover 상자와 text 아이콘 | 노트 상단, 상세 뒤로 가기 |
| 버튼 | 흰 바탕(surface), 옅은 테두리, text 글자 | 흰 바탕 위에 hover | 연결, 다시 로그인, 취소, 되돌리기(warn 글자) |
| 값 버튼 | 회색 바탕, 현재 값과 아래 꺾쇠 | hover 바탕 | 에이전트, 모델, 캘린더 |
| 세그먼트 | 회색 홈, 고른 칸은 흰 바탕 | 고르지 않은 칸에 hover | 화면 모양 |
| 이동 줄 | 오른쪽 끝에 › | 한 줄 이동 줄은 높이 30pt, 두 줄 이동 줄은 줄 높이에서 위아래 4pt씩 뺀 높이의 hover. 반경 6pt, 내용보다 좌우 6pt씩 넓게 | 에이전트 상세로 이동 |
| 글자 링크 | 12pt text-2와 › 또는 ↗ | text, 밑줄 없음 | 모두 보기, 다른 설치 방법 |
| 읽기 전용 값 | text-2 글자 | 반응 없음 | 계정, 요금제, 단축키 |
| 미리보기 | 실제 노트 모양 | 반응 없음 | 설정의 노트 미리보기 |
| 고른 표시 | selected 바탕, text, 굵기 500 | 고르지 않은 줄에 hover | 설정과 라이브러리 사이드바 |
| 값을 하나 고르는 메뉴 | 현재 값 왼쪽에 체크 | 메뉴의 호버 바탕 | 에이전트, 모델, 캘린더, 스페이스 옮기기 |
| 명령 메뉴 | 체크 없이 실행할 동작을 표시한다. 전환 명령은 상태에 따라 글자를 바꾼다 | 메뉴의 호버 바탕 | 항상 위에 고정, 항상 위에 고정 해제 |

### 한 줄 입력칸 체크 목록 (D-132)

- [ ] SwiftUI에서는 `CommandTextField`, AppKit에서는 같은 부품의 네이티브 구현인 `CommandInputField`를 쓴다.
- [ ] 자리 글자와 입력 글자에 같은 글꼴, 크기, 기준선을 적용한다. 색은 역할에 따라 바꿀 수 있다.
- [ ] `ThinCaretFieldEditor`로 커서를 그린다. 조합 중인 문자열은 입력기가 확정할 때까지 유지한다.
- [ ] 빈 칸의 포커스 전후와 첫 글자 입력 전후에 글자 시작점, 기준선, 커서 시작 위치가 1px도 움직이지 않는지 해당 타깃에서 공용 좌표 검사로 확인한다.
