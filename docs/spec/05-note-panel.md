## 5. 노트 창 (화면 1, 2)

### 5.1 구조

```
┌──────────────────────────────────────────────────────┐
│ [스페이스] 제목             (더 보기)(새 노트)  리마인더  핀 │  상단 줄, 높이 chrome-h(28)
├──────────────────────────────────────────────────────┤  1px line
│ 본문 (마크다운)                                        │  안쪽 여백 doc-pad(10 14 18 14)
│                                                      │
│                                        (휴지통)(닫기) │  오른쪽 아래에서 4pt, 본문 위에 겹침
└──────────────────────────────────────────────────────┘
```

- 창: 모서리 `r-window`(10), 바탕 `surface`를 `opacity`(.92)로, 뒤 배경 흐림 `blur`(24). 테두리 1px `outline`, 그림자 `shadow-window`. 모든 노트가 포커스와 상관없이 같은 모습입니다.
- 상단 줄: 왼쪽 여백 12. 오른쪽은 핀 아이콘의 오른쪽 끝이 창 오른쪽에서 12가 되게 둡니다(제목과 좌우 균형, D-039). 요소 사이 6, 나란히 놓인 아이콘 버튼 사이는 `icon-btn-gap`(0)이라 버튼의 `hover` 상자가 맞닿습니다. 괄호 안의 요소는 마우스를 올렸을 때만 보입니다.
- 노트 창은 보통 앱 창처럼 누르면 앱이 앞으로 오고 메뉴 막대가 이 앱의 메뉴로 바뀝니다(D-025). 앱이 뒤로 가도 노트는 숨지 않고, 핀이 켜진 노트는 다른 앱 위에 뜹니다.

### 5.2 상단 줄 요소 (왼쪽부터)

| 요소 | 평소 | 마우스를 올렸을 때 | 누르면 |
| --- | --- | --- | --- |
| 스페이스 | 13pt 아이콘, `text-3`. 스페이스가 없으면 자리 자체가 없음 | `text-2` | (없음) |
| 제목 | `fs-title`(12), `fw-title`(600), `text-3`. 비어 있으면 "제목 없음"을 보통 굵기로 | `text` | 그 자리에서 편집. 상자 없이 글자가 `text`가 되고 커서만 생김 |
| 더 보기, 새 노트 | 보이지 않음(자리는 차지) | `icon-btn`(18pt) 아이콘 버튼 둘, `text-2` | 5.4, 새 노트 |
| 리마인더 | 12pt 아이콘과 시간. 사이 `icon-gap`(3). 없으면 자리 없음 | 그대로 | 리마인더 설정 |
| 핀 | 켜져 있으면 채운 핀. 꺼져 있으면 보이지 않음(자리는 차지) | 꺼진 핀이 외곽선으로 나타남 | 항상 위에 고정을 켜고 끔 |

- 스페이스 표시 방식(설정): 아이콘(기본), 아이콘+이름, 이름.
- 리마인더 표시 방식(설정): 시간(기본), 남은 시간("12분 후"), 아이콘만. 시간 형식(설정): `3:00 PM`, `오후 3:00`(기본, D-066), `15:00`. 오늘이 아니면 날짜를 앞에 붙입니다("내일 오전 10:00", "수 오후 2:00").
- 리마인더 상태: 예정은 상단 줄 색 그대로 시계 아이콘. 임박은 `warn` 색, 종 아이콘(1.6초마다 흔들림), 굵기 700. 지남은 `warn` 색, 시계 아이콘, 보통 굵기. 세 상태 모두 크기와 위치가 같습니다. 임박의 기준은 15분 전부터입니다(D-067).

- 제목은 한 줄로 저장합니다. Return·Option+Return·줄/문단 구분 명령은 편집을 끝냅니다. 여러 줄 입력은 조합 중에는 유지하고 확정/편집 종료 때 개행을 공백으로 바꿉니다(CRLF는 공백 하나). 저장소의 생성·수정에서도 같은 규칙을 적용합니다(D-059).

### 5.3 오른쪽 아래 버튼

- 휴지통(14pt)과 닫기 ×(13pt). 각각 `icon-btn`(18pt) 아이콘 버튼, 사이 `icon-btn-gap`(0). 아래 모서리에서 4pt, 오른쪽은 닫기 아이콘의 오른쪽 끝이 핀과 같은 세로줄(12)에 오게 본문 위에 겹쳐 뜹니다.
- 아이콘은 크기 토큰(`icon-s|m|l`)의 칸 안에 드는 크기로 그리고, 눈으로 커 보이는 것(채운 핀, 휴지통, 더 보기)만 `iconOptical` 표로 줄입니다(키우지 않음, D-039). 같은 줄의 아이콘은 같은 가운데 선에 놓입니다.
- 본문 아래 여백(18pt)이 이 자리를 비워 두므로 마지막 줄 글자와 겹치지 않습니다.
- × 는 창만 내립니다. 노트는 라이브러리에 남고 다시 띄울 수 있습니다.
- 휴지통은 노트를 휴지통으로 보냅니다. 확인 창을 띄우지 않습니다. 보낸 뒤 화면 가운데 아래쪽에 "휴지통으로 보냈습니다"와 "되돌리기"가 든 짧은 알림이 잠깐 뜹니다(D-041). 라이브러리의 휴지통에서 되살릴 수 있고, 바로 뒤라면 ⌘Z나 알림의 "되돌리기"로 되돌립니다. 30일 뒤에 완전히 지웁니다(가정).
- 제목과 본문이 비었거나 공백뿐이고 리마인더가 없는 노트는 창을 닫을 때와 앱을 끝낼 때 휴지통을 거치지 않고 지웁니다(D-040). 무엇이든 적힌 노트는 지우지 않습니다.

### 5.4 더 보기 메뉴

순서대로: 리마인더 설정, 스페이스 옮기기, 항상 위에 고정, 노트 색 줄 / 노트 찾기, AI 패널 열기 / 창 닫기, 휴지통으로 보내기. 노트 찾기는 마우스를 올렸을 때의 아이콘에서 이 메뉴로 옮겼습니다(⌘P는 그대로, D-039).

- 노트 색 줄은 물방울 아이콘 뒤에 색 칸 아홉 개(없음 + 팔레트 여덟)가 한 줄로 놓입니다. 칸은 13pt, 모서리 3, 사이 5. 고른 칸에는 1.5pt `text` 테두리가 1.5pt 떨어져 붙습니다. 색 칸 위에 마우스를 올리면 `text-3` 테두리가 나타납니다.
- 메뉴 항목 높이 26, 왼쪽 14pt 정렬 칸 안에 `menu-icon`(12pt) 그림(D-058). 올리면 `hover` 바탕. 줄과 구분선의 바탕은 불투명한 `surface`라 뒤의 노트가 비치지 않습니다. 고를 수 없는 항목은 `text-3`입니다(D-039).

### 5.5 상태 조합

| | 마우스가 밖 | 마우스가 위 |
| --- | --- | --- |
| 포커스 없음 | 제목, 스페이스, 리마인더, 핀만 흐리게 | 제목 진하게, 아이콘 둘과 휴지통, 닫기 나타남 |
| 포커스 있음 | 위와 같고 커서만 더해짐 | 위와 같고 커서만 더해짐 |

네 경우 모두 창 크기와 요소 위치가 같아야 합니다. 제목 표시와 필드 편집기도 같은 기준선을 사용합니다(D-055).

### 5.6 크기

- 너비는 사용자가 가장자리를 끌어 바꿉니다.
- 높이는 내용에 맞춥니다. 다만 본문 영역은 적어도 본문 네 줄 높이입니다(`note-body-lines-min`, D-031. 한두 줄만 보이는 노트는 너무 작습니다). 토글을 접고 펴거나 줄이 늘면 창 높이가 `dur` 동안 따라갑니다(가정. 사용자가 아직 답하지 않음). 화면 높이의 70%를 넘으면 그 안에서 스크롤합니다(가정).
- 긴 제목은 말줄임표로 자릅니다. 호버 아이콘 자리는 항상 비워 두므로 평소에도 그 앞에서 잘립니다.


- 6단계: 여러 예정 중 가장 이른 다가오는 것 하나를 표시하며 일정은 캘린더 아이콘과 범위입니다. 설정·연동 실패·양방향 완료는 [21장](21-schedule.md)을 따릅니다.
