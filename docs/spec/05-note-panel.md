## 5. 노트 창 (화면 1, 2)

### 5.1 구조

상단 줄 높이는 32pt이며 본문 안쪽 여백은 위아래 12pt, 좌우 16pt입니다. 창은 `r-window`, `surface`, `outline`, `shadow-window`를 씁니다.

- 노트 창은 보통 앱 창처럼 누르면 앱이 앞으로 오고 메뉴 막대가 이 앱의 메뉴로 바뀝니다(D-025). 앱이 뒤로 가도 노트는 숨지 않고, 핀이 켜진 노트는 다른 앱 위에 뜹니다.

### 5.2 상단 줄 요소 (왼쪽부터)

| 요소 | 평소 | 노트에 마우스를 올렸을 때 |
| --- | --- | --- |
| 제목 | 13pt, 굵기 600, `text-3` | `text`, 눌러 한 줄 편집 |
| 예정 | 미완료, 미삭제 예정이 있으면 시계 버튼. 기본 `text-3`, 임박하면 `warn` | 같은 시계를 누르면 이 노트의 일정 목록. 버튼에 올리면 `text`와 `hover` |
| 조작 | 고정된 노트는 오른쪽 끝에 채운 핀을 `text-3`로 표시. 시계는 핀 왼쪽, 핀이 숨겨지면 오른쪽 끝 | 시계(예정이 있을 때), 핀, 더 보기, 구분선, 닫기 순서. 고정된 핀은 채움과 `text-2`, 버튼에 올리면 `text`와 `hover` |

- 고정된 핀은 호버 조작이 나타날 때 같은 `dur`와 `ease`로 더 보기 왼쪽으로 이동합니다. 동작 줄이기에서는 즉시 이동합니다. 평소에도 같은 버튼을 눌러 고정을 해제할 수 있고, 머리 줄의 빈 곳을 끌어 창을 옮깁니다(D-189).
- 시계는 호버 전후에 고정 핀과 같은 `dur`와 `ease`로 이동하며 동작 줄이기에서는 즉시 이동합니다. 제목의 기준선과 글꼴의 대문자 높이로 글자의 시각 중심을 아이콘 칸의 세로 중심에 맞춥니다. 제목 아래에는 평소에도 `line` 구분선을 표시합니다.
- 노트 상단 아이콘 칸은 20pt, 칸 사이는 2pt입니다. 이웃 조작 사이의 누름은 중앙선을 기준으로 가까운 쪽이 받습니다. 구분선 양옆은 6pt, 오른쪽 끝 여백은 8pt입니다(D-245). 그림은 14pt, 선은 1.4pt이며 끝은 둥글게 그립니다. 호버 바탕 모서리는 5pt입니다.
- 시계의 도움말과 접근성 이름에 가장 이른 예정의 시간, 임박 여부, 다가올 추가 건수 `+N`을 둡니다. 오늘의 날짜 전용 예정은 하루 동안 포함합니다. 지난 예정만 남으면 시계는 `text-3`이고 도움말과 접근성 이름에 “이 노트의 일정”과 남은 건수를 둡니다. 완료, 삭제된 항목만 있으면 호버 중에도 시계를 숨깁니다.

- 시계에서 연 예정 팝오버의 입력은 Return으로 제출한다. 바깥을 누르거나 다른 창이나 앱으로 가면 미완성 초안을 버리고 닫는다(D-097).
- 제목은 한 줄로 저장합니다. Return, Option+Return, 줄/문단 구분 명령은 편집을 끝냅니다. 여러 줄 입력은 조합 중에는 유지하고 확정/편집 종료 때 개행을 공백으로 바꿉니다(CRLF는 공백 하나). 저장소의 생성, 수정에서도 같은 규칙을 적용합니다(D-059).

### 5.3 오른쪽 아래 버튼

- F1은 왼쪽부터 굵게, 취소선, 형광펜, 인라인 코드, 링크, 구분선, 체크 목록, 글머리 목록입니다. 현재 위치나 굵게 입력 상태가 켜진 버튼은 `format-active` 바탕과 `text` 아이콘을 씁니다(D-184). 꺼진 버튼은 `text-2` 아이콘이며 올리면 `hover` 바탕과 `text` 아이콘이 나타납니다. 기본은 숨김입니다. 설정의 모양이나 노트 더 보기에서 켜면 본문에 커서가 있는 동안 표시합니다. 꺼져 있으면 본문이 아래 끝까지 차지합니다. 창 높이는 같습니다(D-257, D-258). 열려 있는 노트로 포커스가 돌아와 서식 막대가 나타나면 읽던 스크롤 위치를 유지합니다(D-280).
- 휴지통 동작은 더 보기 메뉴의 마지막 줄에 둡니다.

- × 는 창만 내립니다. 노트는 라이브러리에 남고 다시 띄울 수 있습니다.
- 휴지통은 노트를 휴지통으로 보냅니다. 확인 창을 띄우지 않습니다. 보낸 뒤 노트 창이 있던 자리 아래쪽 가운데에 "휴지통으로 보냈습니다"와 "되돌리기"가 든 짧은 알림이 잠깐 뜹니다(D-041). 라이브러리의 휴지통에서 되살릴 수 있고, 바로 뒤라면 ⌘Z나 알림의 "되돌리기"로 되돌립니다. 휴지통의 노트는 자동으로 지우지 않습니다(D-161).
- 제목과 본문이 비었거나 공백뿐이고 리마인더가 없는 노트는 창을 닫을 때와 앱을 끝낼 때 휴지통을 거치지 않고 지웁니다(D-040). 무엇이든 적힌 노트는 지우지 않습니다.

### 5.4 더 보기 메뉴

새 노트 / 리마인더 설정, 스페이스 옮기기, 항상 위에 고정, 노트 색 줄 / 노트 찾기, 라이브러리, 서식 막대 보이기 또는 숨기기 / 창 닫기, 보관함으로, 휴지통으로 보내기 순서입니다. 묶음 사이에는 구분선을 둡니다. 새 노트는 같은 스페이스에 만들고 현재 창 옆에 엽니다(D-129). 노트 찾기는 마우스를 올렸을 때의 아이콘에서 이 메뉴로 옮겼습니다(⌘P는 그대로, D-039). 라이브러리는 기존 단축키 ⌃⌥L을 유지하고 키 글자는 13장의 표에만 표시합니다.

- 노트 색 줄은 물방울 아이콘 뒤에 색 칸 아홉 개(없음 + 팔레트 여덟)가 한 줄로 놓입니다. 칸은 13pt, 모서리 3, 사이 5. 고른 칸에는 1.5pt `text` 테두리가 1.5pt 떨어져 붙습니다. 색 칸 위에 마우스를 올리면 `text-3` 테두리가 나타납니다.
- 메뉴 너비는 210pt, 행 높이는 28pt다. 고정 상태에 따라 항상 위에 고정 또는 항상 위에 고정 해제로 표시하고 접근성 이름도 일치시킨다. 보관 상태에서는 보관함으로가 되돌리기로 바뀐다. 명령 줄에는 체크 칸이 없다(D-174). 왼쪽 아이콘 칸 안에 `menu-icon`(12pt) 그림(D-058). 올리면 `hover` 바탕. 줄과 구분선의 바탕은 불투명한 `surface`라 뒤의 노트가 비치지 않습니다. 고를 수 없는 항목은 `text-3`입니다(D-039).

- 더 보기 메뉴의 라이브러리를 고르면 기존 라이브러리 창을 열고 앞으로 가져온다. 더 보기 메뉴를 열기만 할 때는 라이브러리를 열지 않는다. 노트를 누르거나 키 창으로 삼을 때 활성화 전에 그 노트를 main 문서 창으로 지정한다. 이전 라이브러리가 main으로 남아 활성화 때 따라 올라오는 것을 막는다(D-080, D-083).

### 5.5 상태 조합

제목과 예정이 있는 노트의 시계는 포커스와 호버에 관계없이 표시합니다. 고정된 핀은 평소에도 보이고, 나머지 상단 조작은 노트 호버로, 서식 버튼은 설정을 켰고 해당 노트 본문에 포커스가 있을 때 표시합니다. 제목 표시와 편집 기준선은 같습니다.

### 5.6 크기

- 너비는 사용자가 가장자리를 끌어 바꿉니다. 260부터 560까지, 기본 340입니다(D-158).
- 기본은 고정입니다. 새 창은 머리 줄과 구분선, 본문 여섯 줄, 본문 위아래 여백으로 높이를 정합니다. 줄이 늘거나 서식 막대가 나타나도 위쪽 끝과 높이를 유지하고 창 안에서 스크롤합니다. 새 창을 열 때 현재 글자 크기와 줄 간격을 사용합니다(D-247, D-254, D-255).
- 글에 맞춤을 고르면 저장 높이가 없는 노트는 네 줄을 최소로 하여 내용에 맞춰 변합니다. 화면 높이의 70%와 화면 아래 끝에서 멈춥니다. 고정으로 돌아오면 열린 창의 당시 높이를 노트에 저장합니다(D-158, D-252, D-253).
- 글에 맞춤에서 줄이 늘거나 줄면 위쪽 끝을 고정하고 `dur`, `ease`로 높이를 바꿉니다. 연속 편집은 진행 중인 목표를 갱신하며 동작 줄이기에서는 즉시 맞춥니다. 높이가 변하는 동안에는 스크롤 막대를 숨깁니다. 고정 높이나 화면 한도에서 본문이 넘치면 사용자가 스크롤할 때 작은 시스템 막대가 보입니다. 시스템이 항상 표시를 사용하면 그 설정을 따릅니다(D-312).
- 직접 바꿀 때는 본문 네 줄부터 화면 표시 영역 전체까지입니다. 직접 정한 높이와 고정으로 전환하며 기억한 높이는 두 모드에서 닫았다 열거나 앱을 다시 켜도 유지합니다. 작은 화면에서 줄여 표시해도 원래 높이를 보존합니다. 옛 창은 마지막 프레임의 높이를 이어받고 프레임이 없으면 새 창 규칙을 따릅니다(D-249, D-250, D-251).
- 긴 제목은 창 너비에 따라 줄여 버튼을 누를 공간을 확보합니다. 일정 설정과 연동은 [21장](21-schedule.md)을 따릅니다.
