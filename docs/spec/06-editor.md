## 6. 본문 편집기

마크다운을 입력하면 그 자리에서 서식이 입혀지고 기호는 사라집니다. 미리 보기 모드가 따로 없고, 기호는 편집 중에도 보이지 않습니다(D-036). 저장되는 글은 Markdown 원문 그대로입니다.

| 요소 | 입력 | 모습 |
| --- | --- | --- |
| 제목 1, 2, 3 | 줄 맨 앞에 `#`, `##`, `###` 치고 Space | `fs-h1` 17/24 굵기 700, `fs-h2` 15/22 굵기 650, `fs-h3` 13/20 굵기 650 |
| 본문 | 제목, 목록의 글자 맨 앞에서 ⌫ | `fs-body` 13, 줄 높이 20 |
| 투두 | 줄 맨 앞에 `[]` 치고 Space | 13pt 상자, 모서리 `r-check`(3), 1.25pt `text-2` 테두리. 완료하면 상자가 `text-3`로 채워지고 체크는 `surface` 색, 글자는 `text-3`에 취소선 |
| 글머리표 | 줄 맨 앞에 `-` 치고 Space | 단계마다 채운 원(5pt), 빈 원, 채운 사각(4pt, `text-2`) |
| 토글 | 줄 맨 앞에 `>` 치고 Space | 12pt 꺾쇠(접힘은 오른쪽, 펼침은 아래), 제목 뒤에 안의 줄 수를 `fs-micro`, `text-3`로 |
| 굵게 | `**글자**` 또는 ⌘B | 굵기 `fw-strong`(650) |
| 취소선 | `~~글자~~` 또는 ⇧⌘X | `text-2`, 1pt 선 |
| 형광펜 | `==글자==` 또는 ⇧⌘H | 바탕 `hl-1-bg`부터 `hl-4-bg`, 모서리 `r-hl`(2), 좌우 2pt. 단축키를 다시 누르면 다음 색 |
| 인라인 코드 | `` `글자` `` 또는 ⌘E | D2Coding `fs-code`(11.5). 글자는 코드 강조색 `code-accent`(기본) 또는 `code-fg`(설정 `inline-code`: `accent`, `plain`). 바탕 `code-bg`, 테두리 없음, 모서리 `r-code`(4.5), 좌우 안쪽 `code-pad-x`(4.5), 바깥 `code-gap`(1.5). 상자 높이 `code-h`(16)로 고정하고 글자 위아래가 같게 놓음. 제목 안에서는 제목 크기에 비례 |
| 코드 블록 | 줄 맨 앞에 백틱 셋(이어 누른 Return이나 Space 하나는 넣지 않음) 또는 ⌥⌘C | 가로로 꽉 찬 상자. 안쪽 `codeblock-pad-y` `codeblock-pad-x`(9 12), 모서리 `r-codeblock`(8), 바탕 `codeblock-bg`, 테두리 없음, 위아래 바깥 `codeblock-gap`(5). D2Coding 11.5/18(`lh-code`), 줄바꿈함. 글자는 언제나 `code-fg`, 주석은 `text-3`. 구문 색은 없음. 블록에 마우스를 올리면 오른쪽 위에 복사 아이콘 버튼 |
| 링크 | 글자를 고르고 ⌘L, 또는 주소 붙여넣기 | 글자만 보임(주소는 감춤). `text` 색에 `text-3` 밑줄. 올리면 밑줄이 `text`로. 누르면 열림 |

- **줄 왼쪽 칸**: 체크박스, 꺾쇠, 글머리표는 너비 `gutter`(22)의 칸에 놓이고 글자는 그 뒤에서 시작합니다.
- **하위 계층**: Tab 한 번에 `indent`(22)만큼 들어갑니다. ⇧Tab으로 나옵니다. 부모 글머리 중심 아래로 1pt `guide` 안내선이 이어집니다. 최소 3단계를 지원합니다.
- **기호는 보이지 않습니다.** 커서가 있는 줄에서도 `#`, 목록 기호, `**`, `~~`, `==`(색 번호 `{n}` 포함), 백틱, 링크의 `[`와 `](주소)`, 코드 블록의 ` ``` ` 줄(언어 이름 포함)이 나타나지 않습니다. 원문에는 그대로 남습니다.
- **줄의 종류 바꾸기.** 표의 기호를 글자가 보이기 시작하는 자리에 치고 Space를 누르면 그 줄이 바뀝니다. 빈 줄, 글이 있는 줄, 이미 다른 종류인 줄 모두에서 됩니다(제목 줄 맨 앞에 `-` Space를 치면 글은 그대로인 채 글머리표가 됨). 들여쓰기는 그대로입니다. 되돌리면 친 기호가 보통 글자로 남고, 한 번 더 되돌리면 그것도 지워집니다. 글자 맨 앞에서 ⌫를 누르면 본문이 되고(들여 쓴 줄은 그다음 ⌫마다 한 단계씩 나옴), 그다음 ⌫가 윗줄과 합칩니다.
- **인라인 서식.** 닫는 기호를 치는 순간 바뀌고 기호가 사라집니다. 그 뒤에 이어 치는 글자는 서식이 없습니다. 단축키는 고른 글자에 서식을 입히거나 벗기고(구간의 일부만 고르면 그 부분만), 고른 것이 없으면 다음에 칠 글자의 서식을 켜고 끕니다. 서식 구간의 끝에서 이어 치면 서식이 이어지고, 단축키로 끄거나 →를 한 번 더 누른 뒤에 치는 글자는 서식이 없습니다. 구간의 앞에서 치는 글자는 서식이 없습니다(줄 맨 앞에서만 서식이 붙음). 커서 규칙의 전체는 D-036.
- **감춘 기호와 커서.** 커서는 기호 한가운데에 놓이지 않습니다. 화살표, 낱말 이동, Shift 선택, 누르기와 끌기는 기호를 너비 없는 것으로 다룹니다. ⌫와 ⌦는 언제나 보이는 글자를 지우고, 구간의 보이는 글자가 모두 지워지면 기호도 함께 지워집니다.
- **링크.** 글자를 고르고 ⌘L을 누르면 그 아래에 주소를 적는 작은 칸이 뜹니다(Return으로 넣고 Esc로 그만둠). 커서가 링크 안에 있을 때 ⌘L을 누르면 주소를 고치고, 주소를 비우면 링크가 풀립니다. 링크의 글자는 보통 글자처럼 고칩니다.
- **코드 블록.** 백틱 셋으로 들어갑니다. 빈 마지막 줄에서 Return을 누르면 그 줄이 지워지고 블록 아래에 문단이 열립니다. 문서가 블록으로 끝나면 마지막 줄에서 ↓가 아래에 문단을 만듭니다(문서가 블록으로 시작하면 첫 줄에서 ↑가 위에). 빈 블록의 맨 앞에서 ⌫를 누르면 블록이 없어집니다. 여는 줄의 언어 이름은 원문에 남고 보이지 않습니다. 닫는 줄이 없는 블록(다른 프로그램이 쓴 파일)은 문서 끝까지 코드로 보이고, 빠져나갈 때 닫는 줄을 넣습니다.
- **체크박스 모양**(설정): 상자(기본) 또는 대괄호. 대괄호는 D2Coding으로 `[ ]`, 완료는 `[x]`이고 이때 `gutter`는 28입니다.
- 줄 옮기기, 접기, 서식 단축키는 13장에 있습니다.
