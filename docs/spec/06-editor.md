## 6. 본문 편집기

마크다운을 입력하면 그 자리에서 스타일이 입혀집니다. 미리 보기 모드가 따로 없습니다.

| 요소 | 입력 | 모습 |
| --- | --- | --- |
| 제목 1, 2, 3 | `#`, `##`, `###` 뒤에 Space | `fs-h1` 17/24 굵기 700, `fs-h2` 15/22 굵기 650, `fs-h3` 13/20 굵기 650 |
| 본문 | | `fs-body` 13, 줄 높이 20 |
| 투두 | `[]` 뒤에 Space | 13pt 상자, 모서리 `r-check`(3), 1.25pt `text-2` 테두리. 완료하면 상자가 `text-3`로 채워지고 체크는 `surface` 색, 글자는 `text-3`에 취소선 |
| 글머리표 | `-` 뒤에 Space | 단계마다 채운 원(5pt), 빈 원, 채운 사각(4pt, `text-2`) |
| 토글 | `>` 뒤에 Space | 12pt 꺾쇠(접힘은 오른쪽, 펼침은 아래), 제목 뒤에 안의 줄 수를 `fs-micro`, `text-3`로 |
| 굵게 | `**글자**` | 굵기 `fw-strong`(650) |
| 취소선 | `~~글자~~` | `text-2`, 1pt 선 |
| 형광펜 | `==글자==` | 바탕 `hl-1-bg`부터 `hl-4-bg`, 모서리 `r-hl`(2), 좌우 2pt. 단축키를 다시 누르면 다음 색 |
| 인라인 코드 | `` `글자` `` | D2Coding `fs-code`(12), 바탕 `code-bg`, 1pt `code-line` 테두리, 모서리 `r-code`(4), 좌우 4pt |
| 코드 블록 | ` ``` ` | 가로로 꽉 찬 상자. 안쪽 7 10, 모서리 `r-codeblock`(6), 바탕과 테두리는 인라인과 같음. D2Coding 12/18, 줄바꿈함. 주석은 `text-3`. 구문 색은 없음. 블록에 마우스를 올리면 오른쪽 위에 복사 아이콘 버튼 |
| 링크 | `[글자](주소)` 또는 주소 붙여넣기 | `text` 색에 `text-3` 밑줄. 올리면 밑줄이 `text`로 |

- **줄 왼쪽 칸**: 체크박스, 꺾쇠, 글머리표는 너비 `gutter`(22)의 칸에 놓이고 글자는 그 뒤에서 시작합니다.
- **하위 계층**: Tab 한 번에 `indent`(22)만큼 들어갑니다. ⇧Tab으로 나옵니다. 부모 글머리 중심 아래로 1pt `guide` 안내선이 이어집니다. 최소 3단계를 지원합니다.
- **편집 중인 줄에만 마크다운 기호가 보입니다.** 커서가 있는 줄에서는 `==`, `~~`, `**` 같은 기호가 `text-3`, D2Coding으로 나타나고, 커서가 떠나면 사라집니다. 코드 블록의 ` ``` ` 줄도 커서가 블록 안에 있을 때만 보입니다.
- **체크박스 모양**(설정): 상자(기본) 또는 대괄호. 대괄호는 D2Coding으로 `[ ]`, 완료는 `[x]`이고 이때 `gutter`는 28입니다.
- 줄 옮기기, 접기, 서식 단축키는 13장에 있습니다.
