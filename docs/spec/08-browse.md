## 8. 노트 찾기

노트의 더 보기 메뉴, ⌘P, 메뉴 막대와 앱 메뉴에서 연다. 노트에서 열면 원래 노트는 결과에서 제외하고 검색칸에 포커스를 둔다.

- 폭 300pt, 모서리 12pt와 시스템 패널 그림자를 쓴다. 검색칸은 높이 30pt, 바탕과 테두리 없이 13pt 돋보기(text-3), 자리 글자 ‘노트 찾기’(text-4)를 둔다. 아래 선은 양끝에서 14pt 띄운다.
- 기본 목록의 머리는 ‘최근’(11pt, text-3, 높이 20pt)이다. 창이 마지막으로 키 창이 된 시각이 가까운 순서로 최대 여덟 줄이다. 포커스 기록이 없는 노트와 보관함, 휴지통은 제외한다. 시각은 로컬 창 상태에 저장한다(D-130).
- 줄은 높이 26pt, 바깥 여백 5pt, 안쪽 여백 9pt다. 13pt 스페이스 아이콘이나 기본 문서 아이콘, 13pt 보통 굵기 제목을 표시한다. 빈 제목은 ‘제목 없음’과 text-3을 사용한다. 선택 바탕은 가벼운 무채색, 모서리 6pt다.
- 오른쪽 끝 20pt 칸에 12pt 핀을 둔다. 열려 있고 항상 위에 고정된 노트는 채운 핀을 표시한다. 나머지는 행을 선택한 동안 빈 핀을 표시한다. 핀만 눌러 고정 상태를 전환하며 닫힌 노트를 고정할 때는 검색 포커스를 유지한 채 창을 띄운다. 행을 누르면 노트를 연다.
- 검색 중에는 머리를 숨기고 휴지통을 제외한 전체 노트에서 찾는다. 제목 일치가 본문 일치보다 먼저이고, 각 그룹에서 최근에 본 노트가 먼저다. 보관함은 마지막에 같은 순서로 둔다. 같은 시각이나 기록이 없는 노트끼리는 저장소 순서를 유지한다.
- 제목 일치는 해당 글자만 굵기 600이다. 본문만 일치하면 제목 다음에 앞뒤 문맥을 12pt text-3으로 놓고 일치한 글자만 굵기 600과 text-2로 표시한다. 앞 문맥은 기본 여덟 글자에서 공백이나 쉼표를 경계로 최대 열두 글자까지 낱말 시작을 찾는다. 범위 안에 앞쪽 경계가 없으면 다음 낱말이나 일치 지점에서 시작하고, 본문 앞을 생략했으면 …를 붙인다. 제목과 문맥은 기준선을 공유한다. 호버와 선택으로 바뀌는 것은 색과 핀 표시뿐이다(D-055).
- 결과가 여덟 줄을 넘으면 결과만 스크롤한다. 그 아래에 ‘“검색어” 새 노트 만들기’(+, text-2), 구분선, ‘라이브러리 열기’를 둔다. 결과가 없으면 만들기 줄이 처음부터 선택된다.
- 위아래 방향키로 선택하고 Return으로 연다. 한글 입력기가 조합을 확정한 Return 한 번으로 연다. Esc는 닫고 기존 포커스를 돌려준다. 목록 갱신 때 선택은 노트 ID를 따라간다.
