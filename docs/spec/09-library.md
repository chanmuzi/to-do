## 9. 라이브러리 (화면 4)

### 9.1 사이드바 (2판, D-133~D-139)

- 너비 `library-sidebar-w` 240, 바탕 `surface-2`. 신호등 줄 52pt 바로 아래에서 보기 구획이 시작한다. 노트 검색은 노트 찾기(⌘P)에서 한다(D-126).
- 구획은 보기, 에이전트, 스페이스, 아카이브, 다가오는 일정 순서다. 구획 이름은 Pretendard 11, 굵기 500, `text-3`. 구획 사이 11pt, 머리 높이 22pt.
- 줄 높이 `row-h` 28, 사이 `library-sidebar-row-gap` 2. 고른 줄은 둥근 `selected`와 중간 굵기 500, 호버는 옅은 `hover`다. 두 상태 모두 테두리가 없다.
- 보기에는 오늘, 고정됨, 전체 노트가 기본이다. 설정의 일반 화면에서 각 보기의 표시와 순서를 정한다. 사이드바에서는 보이는 줄 전체를 위아래로 끌거나 오른쪽 클릭 메뉴의 위로, 아래로로 옮긴다. 꺼진 보기의 자리는 보존한다. 처음에는 오늘, 이후에는 기본으로 마지막에 본 곳을 연다. 마지막 위치 기억을 끄면 맨 위의 켜진 보기, 모두 꺼져 있으면 전체 노트를 연다.
- 스페이스 없음 항목은 표시하지 않는다. 예전 `.space(nil)`과 `.day(nil, date)` 저장값은 계속 디코딩하며 열 때 전체 노트로 이동한다. 소속 없는 노트의 전체, 오늘, 고정됨 조회는 유지한다.
- 스페이스도 줄 전체를 세로로 끌어 같은 구획에서만 옮긴다. 펼친 날짜는 부모 스페이스를 따라간다. 클릭과 끌기의 문턱은 macOS의 kMouseParamsDragInitiation으로 읽는다. 클릭은 선택하며 꺾쇠는 펼치고 더 보기는 메뉴를 연다. 날짜 줄은 D2Coding, 오늘 아닌 날짜와 아카이브는 `text-3`.
- 스페이스 구획의 +는 아이콘과 이름을 함께 정하는 입력 줄을 연다. 이름 왼쪽 버튼에서 기존 아이콘 선택기를 열고 Return으로 둘을 함께 저장한다. 빈 이름은 만들 수 없으며 Escape와 바깥 클릭은 취소한다. 아이콘이 없으면 사이드바에 폴더를 표시한다. 보기, 휴지통, 스페이스와 입력 줄의 아이콘 중심과 이름 시작선은 같다. 이름을 고칠 때도 해당 행과 같은 글꼴, 크기, 굵기를 쓴다. 그림은 14pt, 왼쪽 클릭 칸은 24pt다. 호버하면 왼쪽 아이콘이 펼치기 꺾쇠로 바뀌며 펼치면 아래쪽 꺾쇠를 계속 표시한다. 오른쪽 더 보기 칸은 20pt, 그림 12pt, 모서리 5pt이며 항상 자리를 차지한다. 이름을 누르면 그 스페이스를 선택한다.
- 보기, 스페이스, 보관함, 휴지통의 개수는 표시하지 않는다. 고정됨은 창 열림과 별개인 isPinned를 따른다.
- 스페이스의 더 보기와 오른쪽 클릭은 같은 NSMenu다. 이 스페이스에 새 노트, 구분선, 아이콘 바꾸기, 이름 바꾸기, 구분선, 위로, 아래로, 구분선, 스페이스 지우기 순서이며 모든 명령에 SF Symbol을 붙인다. 노트 문맥 메뉴도 기존 순서로 모든 명령에 아이콘을 붙인다.
- 다가오는 일정은 색 점(리마인더는 빈 점), 제목, 오른쪽 시작 시각 순서다. 시작은 본문 글꼴 12pt, text-3, 같은 폭 숫자다. 오늘은 시계 설정에 따라 ‘오후 5:00’, 내일은 ‘내일 10:00’, 같은 달력 주는 ‘금 9:00’, 그 밖은 ‘11월 25일’처럼 쓴다. 내일과 요일의 시각은 24시간제다. 날짜 전용 항목에는 시각을 붙이지 않는다. 상세에서 종료 시각까지 표시한다. 5개를 초과하면 첫 다섯 줄 바로 아래의 모두 보기로 펼친다. 펼치면 모든 일정 줄이 연속으로 나오고 마지막 일정 아래의 간단히 보기로 접는다. 연결이 있는 회차를 먼저 남기는 규칙은 21장을 따른다.
- 모두 보기와 간단히 보기는 목록 오른쪽 아래 20pt 줄이며 12pt text-2 글자와 ›를 쓰고 호버 때 text가 된다. 밑줄은 없다.
- 일정 행을 누르면 그 행에 꼬리를 둔 216pt 상세가 열린다. 같은 행과 바깥 클릭은 닫고 다른 행 클릭은 옮긴다. 열린 행은 `selected`다. 상세 여백은 위 10, 좌우 12, 아래 6이다. 제목 13/600, 기간 12, 캘린더 점과 이름 12, 마지막 24pt 줄에 연결된 노트 열기 또는 캘린더에서 열기를 표시한다. 구분선은 없다.
- 하단 고정 설정 행은 14pt gearshape와 13pt 글자이며 기존 설정 창을 연다. 구분선 좌우 8, 선 아래 6, 하단 8pt. 두 목록은 macOS 겹침 스크롤바를 쓰고 오른쪽 내용 여백을 둔다.

### 9.2 조용한 두 줄 목록

- 오른쪽 머리 높이도 52pt이며 보기 이름과 새 노트 단추를 둔다. 대화 페이지는 기존 새 대화 단추를 쓴다. 휴지통과 보관함의 새 노트 표시 조건은 기존과 같다.
- 목록 좌우 여백은 20pt, 노트 줄 위아래는 9pt다. 제목은 14/500 `text`이며 휴지통은 보조 글자색이다. 제목이 비면 파싱한 본문 첫 줄을 표시 제목으로 쓰고 나머지를 아래 줄에 쓴다. 둘 다 비면 14/400 `text-3`의 제목 없음을 표시한다.
- 아래 줄은 Pretendard 12.5, `text-3`, 한 줄과 끝 말줄임이다. 본문 첫머리가 비었을 때만 `투두 1개 남음` 같은 남은 개수를 쓴다. 본문이 있으면 투두 요약을 덧붙이지 않는다. 아래 줄이 비면 제목은 세로 가운데다.
- 완료/전체 진행 수를 표시하지 않는다(D-136). 선택과 호버 바탕은 줄 안쪽의 둥근 칸이다.
- 한 번 클릭은 선택, 더블 클릭과 Return은 노트 열기다. 휴지통은 복원 후 연다. 포커스 링은 없다.
- 노트 도움말과 일정 상세는 저장된 상대/절대 날짜 표시를 따른다(D-087). 사이드바의 시작 시각 축약은 D-125를 따른다.
- 빈 목록에는 전체 노트 또는 새 노트 가운데 가능한 동작 하나만 둔다.

목록은 고정됨, 오늘, 어제, 이전 7일, 이전 30일, 연월 순서다. 날짜 묶음은 마지막 수정 날짜를 기준으로 하며 동률은 노트 ID 순서다. 보관함과 휴지통에서는 날짜로만 묶는다.

- 묶음 머리는 고정됨에 핀, 오늘에 해, 다른 날짜에는 달력 그림을 쓴다. 그림은 14pt `text-2`, 이름은 6pt 뒤에 15/19pt, 굵기 600의 `text`로 놓는다. 노트 제목은 14pt 굵기 400이라 머리가 먼저 읽힌다(D-179). 접근성은 이름만 머리로 읽는다. 머리에는 접기 버튼을 두지 않는다. 후속 구현에서 고정한 노트 끝에 평소에도 흐린 채운 핀을 두고 줄에 올리면 핀과 더 보기(24pt, 사이 2pt)를 보인다. 핀은 고정을 전환하고 더 보기는 오른쪽 클릭과 같은 메뉴다(D-215).
- 머리 아래에는 좌우 20pt 여백 사이에 긴 선을 긋는다. 노트 글자와 노트 사이 선은 머리 이름과 같은 40pt에서 시작한다. 묶음 마지막 노트 아래에는 선을 두지 않고 다음 머리까지 24pt를 둔다. 목록은 마지막 노트 줄에서 끝난다(D-183). 선택과 호버 바탕은 들임과 별도로 좌우 8pt, 위아래 2pt다.
- 보기 이름과 같은 머리는 숨긴다. 앞에 다른 묶음이 있으면 간격과 긴 선만 남긴다. 고정됨처럼 묶음이 하나뿐이고 머리가 숨겨지면 여백이나 머리 선 없이 왼쪽 20pt의 노트 줄부터 시작한다(D-177).
- 오늘 보기는 고정 상태와 관계없이 `rows(for:)` 순서의 단일 목록이다. 머리와 들임 없이 노트 사이에만 선을 둔다(D-178).

### 9.3 보관과 복원

- 노트 더 보기와 목록의 문맥 메뉴에서 보관함으로 옮기거나 되돌린다. 보관 상태는 노트 머리의 선택적 archived 참거짓 값으로 저장한다. 체크 완료만으로 보관하지 않는다. 보관하면 일반 보기, 고정됨, 노트 찾기와 빠른 캡처의 추가 목적지에서 제외한다.
- 옛 월별 아카이브 기준일은 최초 전환 시 한 번 저장한다. 필드가 없는 파일은 그때의 경계로 읽고, 되돌리기는 명시적인 false로 남긴다. 기존 본문, 알 수 없는 머리 줄과 파일 위치는 보존한다.
- 오늘 보기는 오늘 생성한 노트와 오늘 리마인더 노트의 합집합이다. 같은 노트는 한 번만 센다.
- 스페이스 삭제는 확인 후 노트의 소속만 해제한다. 휴지통 노트는 복원할 때 삭제된 스페이스 연결을 해제한다.
- 스페이스 삭제의 확인은 시스템 확인 창 대신 루틴과 같은 확인 팝오버로 바꾼다(11c, D-196, 아직 구현하지 않음). 그 스페이스 줄의 오른쪽 끝에서 4pt, 위쪽을 줄에 맞춰 목록 쪽으로 띄워 사이드바의 다른 줄을 가리지 않는다. 글은 `스페이스를 삭제할까요?`와 `노트는 스페이스 없이 남습니다.`, 버튼은 `취소`와 `삭제`다.
- 휴지통도 한 번 클릭은 선택만 한다. 더블 클릭, Return과 '되돌리기'는 복원 후 노트를 연다. 기존 ID 충돌, 저장 실패는 오류로 알리고 덮어쓰지 않는다.
- '리마인더 있는 노트' 보기에는 지난 값도 포함한다(D-052).
- 첫 보기는 오늘이다. 마지막 보기와 보일 보기, 열 때 보여 줄 곳은 `state/library.json`에 저장한다.
- 처음 켤 때 복원할 노트가 없으면 라이브러리가 열린다. 실행 중 다시 열거나 앱을 전환하면 라이브러리가 앞으로 온다(D-101). 설정은 사이드바 하단에서 연다.
- 휴지통은 자동으로 비우지 않는다. 노트는 사용자가 지울 때까지 남는다(D-161).

에이전트 구획 머리에 올리면 14pt 얼굴이 나타나 전체 노트 요청 막대를 연다. 대화 페이지 오른쪽 위와 사이드바 대화 줄에 올렸을 때의 +는 새 대화 창을 연다(D-210, D-212). 구획의 줄은 제안, 대화 순서다. 제안은 요청별로 묶는다. 넓은 창에서는 오른쪽에, 폭 660pt에서는 선택 줄 아래에 미리보기를 둔다. 좁은 창에서 같은 줄을 다시 누르면 접히고 두 번 누르면 대상 노트를 연다. 출처 없는 새 노트의 결과 줄은 해당 제안을 선택한다. 승인한 새 노트의 결과 줄은 생성된 노트를 연다. 새 노트 미리보기에는 제목, 선택한 스페이스와 본문을, 예정 미리보기에는 노트의 칩과 다가오는 일정의 줄을 함께 표시한다. 새 제안을 열람하면 해당 줄과 사이드바의 점이 갱신된다.

대화는 최근 활동의 현지 날짜별로 묶고 최신순으로 놓는다. 한 번 누르면 한 줄을 선택하고 두 번 누르거나 Return을 누르면 그 대화를 연다. 빈 목록에도 머리의 +가 있다. 시각 오른쪽에는 답변 대기인 경우에만 경고 점이 남는다. 줄에 올리면 시각과 점 자리에 24pt 더 보기 버튼과 14pt 그림이 나타난다. 오른쪽 클릭과 더 보기에서 같은 메뉴를 연다. 열기, 이름 바꾸기, 구분선, 지우기 순서다(D-231).

이름 바꾸기는 줄 안에서 시작한다. Return은 저장, Esc는 취소다. 한글 조합 중에는 입력기가 먼저 확정한다. 빈 이름은 편집 전 이름을 유지한다. 지우기는 버튼 아래 4pt에 오른쪽 끝을 맞춘 확인 팝오버를 연다. 제목은 ‘대화를 삭제할까요?’, 설명은 ‘이미 받은 제안과 노트는 그대로 남습니다.’다. 삭제하면 실행을 회수하고 대기열과 대화 파일을 지우고 해당 창을 닫는다. 사용량 기록은 남긴다.
