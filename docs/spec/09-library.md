## 9. 라이브러리 (화면 4)

### 9.1 사이드바 (너비 220, 바탕 `surface-2`)

위에서부터: 신호등 버튼, 검색 칸(높이 26, `surface-3`), 그리고 네 구획.

| 구획 | 줄 |
| --- | --- |
| 보기 | 오늘, 떠 있는 노트, 전체 노트. 보기 편집에서 켜고 끔 |
| 스페이스 | 스페이스마다 한 줄(접고 펼 수 있음). 펼치면 날짜 줄이 들여쓰기되어 나옴 |
| 아카이브 | 달마다 한 줄(`2026-11`), 맨 아래 휴지통 |
| 리마인더 | 다가오는 리마인더. 리마인더 표시 뒤에 노트 제목 |

- 구획 이름: 11.5pt 굵기 700 `text`. 줄: 높이 `row-h`(26), 왼쪽 14pt 아이콘(`text-2`), 오른쪽 끝에 개수(D2Coding `fs-micro`, `text-3`).
- 고른 줄: `accent` 바탕에 `on-accent` 글자. 그 밖의 줄은 올리면 `hover` 바탕.
- 날짜 줄은 D2Coding `fs-ui`로 `11-16 오늘`, `11-13 금`처럼 씁니다. 오늘이 아닌 날짜와 아카이브 줄은 `text-3`입니다.
- 스페이스 줄에 마우스를 올리면 개수 자리에 더 보기 아이콘이 나타납니다(개수는 사라짐, 자리 고정). 메뉴: 아이콘 바꾸기, 이름 바꾸기 / 스페이스 삭제. 줄을 오른쪽 클릭해도 같습니다.
- "스페이스" 구획 이름에 마우스를 올리면 오른쪽에 + (새 스페이스)가 나타납니다.
- 보기 편집: 체크박스 목록(오늘, 떠 있는 노트, 전체 노트, 리마인더 있는 노트)과 "열 때 보여 줄 곳"(기본: 마지막으로 본 보기). 전체 노트는 끌 수 있는 보기 가운데 하나이고 기본으로 열리지 않습니다.

### 9.2 목록

- 머리 줄: 높이 42. 왼쪽에 보기 이름(`fs-pane-title` 14, 굵기 650). 오른쪽에 24pt 아이콘 버튼 셋: AI 패널, 설정, 새 노트.
- 줄: 위아래 여백 6, 왼쪽 20, 오른쪽 14. 제목(`fs-row` 12.5, 줄 높이 18, 굵기 600), 그 아래 본문 첫머리(`fs-row-sub` 11.5, 줄 높이 16, `text-2`). 줄 높이는 47.
- 줄 오른쪽(왼쪽부터, 사이 14): 리마인더 / 진행(`1/3`, D2Coding) / 스페이스 아이콘 / 핀(떠 있는 노트). 없는 정보는 자리를 비워 둡니다. 열 제목은 없습니다.
- 색을 입힌 노트는 줄 바탕에 같은 색(`tint-mix-row`). 올리면 그 위에 `hover`가 겹칩니다.
- 줄을 누르면 그 노트가 뜹니다(이미 떠 있으면 포커스).


### 9.3 날짜, 보관, 복원 (5단계 적용)

- 생성 날짜의 로컬 자정에서 7일 뒤부터 달별 아카이브에 속한다(D-047, spec 20의 6번 임시 값). 파일은 옮기지 않는다.
- 스페이스와 그 날짜 줄에는 아카이브 전 노트만 보인다. 전체·떠 있는 노트에는 아카이브 노트도 포함한다.
- 오늘 보기는 오늘 생성한 노트와 오늘 리마인더 노트의 합집합이다. 같은 노트는 한 번만 센다.
- 사이드바 개수는 검색으로 줄이지 않는다. 검색은 현재 보기의 제목·본문을 대소문자 구별 없이 찾는다.
- 스페이스 삭제는 확인 후 노트의 소속만 해제한다. 휴지통 노트는 복원할 때 삭제된 스페이스 연결을 해제한다.
- 휴지통 줄의 누름과 '되돌리기'는 복원 후 노트를 연다. 기존 ID 충돌·저장 실패는 오류로 알리고 덮어쓰지 않는다.
- 리마인더 구획은 예정 리마인더가 있을 때만 보이고 시각순이다. '리마인더 있는 노트' 보기에는 지난 값도 포함한다(D-052).
- 첫 보기는 오늘이다. 마지막 보기와 보일 보기·열 때 보여 줄 곳은 `state/library.json`에 저장한다.
- 시작·Dock 재열기에 열린 노트가 없으면 라이브러리가 열린다(D-049). AI·설정은 연결 전까지 흐리고 눌리지 않는다.
- 휴지통 30일은 임시 값이며 삭제 시각 저장과 자동 비우기는 아직 구현하지 않는다(D-014, D-052).
