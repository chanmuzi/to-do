## 9. 라이브러리 (화면 4)

### 9.1 사이드바 (L1, D-086)

- 너비 `library-sidebar-w` 220, 바탕 `surface-2`. 검색은 위쪽, 높이 26, `surface-3` 바탕, 테두리와 포커스 링 없음. 왼쪽 돋보기는 `icon-m` 13, 자리표시는 `검색`, `text-3`.
- 구획은 보기, 스페이스, 아카이브, 다가오는 예정 순서다. 구획 이름은 Pretendard 11, 굵기 700, `text-3`. 구획 간격은 `sp-5`.
- 줄 높이 `row-h` 26, 줄 사이 `library-sidebar-row-gap` 2. 고른 줄은 `surface` 바탕, `bw` 1의 `outline` 테두리, 굵은 글자. 호버는 테두리 없는 `hover`. 라이트와 다크에서 같은 원리를 쓴다.
- 보기에는 오늘, 떠 있는 노트, 전체 노트가 기본이다. 보기 편집에서 켜고 끄며 열 때 보여 줄 곳도 고른다. 마지막 보기 기본값은 오늘이다.
- 스페이스 없음 항목은 표시하지 않는다. 예전 `.space(nil)`과 `.day(nil, date)` 저장값은 계속 디코딩하며 열 때 전체 노트로 이동한다. 소속 없는 노트의 전체, 오늘, 떠 있는 노트 조회는 유지한다.
- 스페이스 펼치기, 날짜 줄, 호버 더 보기와 오른쪽 클릭 메뉴는 유지한다. 날짜 줄은 D2Coding, 오늘 아닌 날짜와 아카이브는 `text-3`.
- 스페이스 구획의 +를 누르면 목록 맨 아래에 이름 입력 줄을 만든다. `surface` 바탕, `outline` 테두리와 회색 빈 아이콘 칸. Return은 생성, Escape와 바깥 클릭은 취소한다. 빈 이름은 생성하지 않는다. 이름 바꾸기도 같은 줄에서 편집한다. 아이콘은 생성 후 더 보기에서 바꾼다.
- 다가오는 예정은 왼쪽에 예정 제목, 없으면 노트 제목, 없으면 본문 첫 줄을 쓴다. 모두 비면 종류 이름인 일정 또는 리마인더를 쓴다. 오른쪽 끝 시간은 D2Coding 11, `text-3`, 임박은 `warn`. 시간 칸은 최대 `library-upcoming-time-w` 120으로 제한하고 긴 절대 날짜는 끝 말줄임해 왼쪽 이름을 지킨다. 시계 아이콘은 없다. 대상 선정, 정렬과 개수 규칙은 이번에 바꾸지 않는다.

### 9.2 조용한 두 줄 목록

- 머리 줄 높이 42. 보기 이름과 새 노트 버튼만 표시한다. AI와 설정 버튼은 연결 전까지 숨긴다.
- 줄 높이 `library-row-h` 47, 왼쪽 20, 오른쪽 14. 제목은 Pretendard 12.5, 굵기 600, `text`. 제목이 없으면 본문 첫 줄을 표시 제목으로 쓰고 둘째 줄 이후를 아래 줄에 쓴다. 저장된 노트 제목은 바꾸지 않는다. 본문까지 비면 `제목 없음`, `text-3`.
- 아래 줄은 Pretendard 11.5, `text-2`, 한 줄과 끝 말줄임이다. 본문 첫머리가 비었을 때만 `투두 1개 남음` 같은 남은 개수를 쓴다. 본문이 있으면 투두 요약을 덧붙이지 않는다. 아래 줄이 비면 제목은 세로 가운데다.
- 오른쪽에는 고정 너비 `library-reminder-w`의 시간 하나(D2Coding 11.5, 오른쪽 정렬, `text-2`, 임박 `warn`)와 떠 있는 노트의 `icon-s` 12 핀 칸만 둔다. 시계, 진행 체크와 분수, 스페이스 아이콘 열은 없다.
- 고른 줄은 `surface-3` 바탕과 제목 굵기를 유지한다. `line` 구분선은 줄 안에 겹친다. 색 입힌 노트 바탕과 호버는 유지한다.
- 한 번 클릭은 선택, 더블 클릭과 Return은 노트 열기다. 휴지통은 복원 후 연다. 포커스 링은 없다.
- 공통 `ReminderPresentation`의 저장된 상대/절대 날짜 표시를 노트 도움말, 라이브러리와 사이드바가 함께 따른다(D-087).
- 빈 목록에는 검색 지우기, 전체 노트 또는 새 노트 가운데 가능한 동작 하나만 둔다.

### 9.3 날짜, 보관, 복원 (5단계 적용)

- 생성 날짜의 로컬 자정에서 7일 뒤부터 달별 아카이브에 속한다(D-047, spec 20의 6번 임시 값). 파일은 옮기지 않는다.
- 스페이스와 그 날짜 줄에는 아카이브 전 노트만 보인다. 전체, 떠 있는 노트에는 아카이브 노트도 포함한다.
- 오늘 보기는 오늘 생성한 노트와 오늘 리마인더 노트의 합집합이다. 같은 노트는 한 번만 센다.
- 검색은 현재 보기의 제목, 본문을 대소문자 구별 없이 찾는다.
- 스페이스 삭제는 확인 후 노트의 소속만 해제한다. 휴지통 노트는 복원할 때 삭제된 스페이스 연결을 해제한다.
- 휴지통도 한 번 클릭은 선택만 한다. 더블 클릭, Return과 '되돌리기'는 복원 후 노트를 연다. 기존 ID 충돌, 저장 실패는 오류로 알리고 덮어쓰지 않는다.
- 리마인더 구획은 예정 리마인더가 있을 때만 보이고 시각순이다. '리마인더 있는 노트' 보기에는 지난 값도 포함한다(D-052).
- 첫 보기는 오늘이다. 마지막 보기와 보일 보기, 열 때 보여 줄 곳은 `state/library.json`에 저장한다.
- 시작, Dock 재열기에 열린 노트가 없으면 라이브러리가 열린다(D-049). 라이브러리 머리의 AI, 설정은 연결 전까지 숨긴다.
- 휴지통 30일은 임시 값이며 삭제 시각 저장과 자동 비우기는 아직 구현하지 않는다(D-014, D-052).

- 6단계: 예정 열은 `library-reminder-w` 200px. 여러 예정 중 가장 이른 다가오는 것 하나를 노트 상단과 같은 범위와 날짜 글자로 표시합니다. 오늘 보기는 오늘의 미완료 일정, 리마인더를 모두 검사합니다(spec 21).
