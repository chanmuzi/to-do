## 9. 라이브러리 (화면 4)

### 9.1 사이드바 (2차, D-122, D-123)

- 너비 `library-sidebar-w` 240, 바탕 `surface-2`. 검색은 위쪽, 높이 28, `surface-3` 바탕, 테두리와 포커스 링 없음. 왼쪽 돋보기는 `icon-m` 13, 자리표시는 `검색`, `text-3`.
- 구획은 보기, 스페이스, 아카이브, 다가오는 일정 순서다. 구획 이름은 Pretendard 11, 굵기 500, `text-3`. 구획 사이 20pt, 머리와 첫 줄 사이 4pt.
- 줄 높이 `row-h` 28, 사이 `library-sidebar-row-gap` 2. 고른 줄은 둥근 `selected`와 중간 굵기 500, 호버는 옅은 `hover`다. 두 상태 모두 테두리가 없다.
- 보기에는 오늘, 고정됨, 전체 노트가 기본이다. 보기 편집에서 켜고 끄며 열 때 보여 줄 곳도 고른다. 마지막 보기 기본값은 오늘이다.
- 스페이스 없음 항목은 표시하지 않는다. 예전 `.space(nil)`과 `.day(nil, date)` 저장값은 계속 디코딩하며 열 때 전체 노트로 이동한다. 소속 없는 노트의 전체, 오늘, 고정됨 조회는 유지한다.
- 스페이스 펼치기, 날짜 줄, 호버 더 보기와 오른쪽 클릭 메뉴는 유지한다. 날짜 줄은 D2Coding, 오늘 아닌 날짜와 아카이브는 `text-3`.
- 스페이스 구획의 +는 아이콘과 이름을 함께 정하는 입력 줄을 연다. 이름 왼쪽 버튼에서 기존 아이콘 선택기를 열고 Return으로 둘을 함께 저장한다. 빈 이름은 만들 수 없으며 Escape와 바깥 클릭은 취소한다. 아이콘이 없으면 사이드바에 폴더를 표시한다. 보기, 휴지통, 스페이스와 입력 줄의 아이콘 중심과 이름 시작선은 같다. 그림은 `icon-l`, 아이콘 칸은 `ctl-h`를 쓴다. 입력 줄은 테두리 없는 `selected` 바탕이며 아이콘 버튼에 호버 바탕을 표시한다. 오른쪽 날짜 버튼은 `icon-s`, `text-3`다. 접으면 줄 호버 때만 그림이 보이고 펼치면 계속 보인다. 버튼은 접혀 있어도 키보드와 접근성으로 작동한다.
- 보기와 스페이스, 보관함과 휴지통의 개수는 오른쪽에 본문 글꼴 12pt, text-3, 같은 폭 숫자로 표시한다. 고정됨은 창 열림과 별개인 isPinned를 따른다.
- 다가오는 일정은 색 점(리마인더는 빈 점), 제목, 오른쪽 시작 시각 순서다. 시작은 본문 글꼴 12pt, text-3, 같은 폭 숫자다. 오늘은 시계 설정에 따라 ‘오후 5:00’, 내일은 ‘내일 10:00’, 같은 달력 주는 ‘금 9:00’, 그 밖은 ‘11월 25일’처럼 쓴다. 내일과 요일의 시각은 24시간제다. 날짜 전용 항목에는 시각을 붙이지 않는다. 상세에서 종료 시각까지 표시한다. 5개를 초과하면 모두 보기로 나머지를 펼친다. 연결이 있는 회차를 먼저 남기는 규칙은 21장을 따른다.
- 0.5초 호버하면 옆에 상세가 뜨고 이탈하면 닫힌다. 클릭하면 그 행의 선택과 상세가 바깥 클릭까지 유지된다. 상세에는 제목, 시각, 캘린더 색과 이름, 구분선 뒤에 연결 노트 또는 캘린더에서 열기 동작이 있다.

### 9.2 조용한 두 줄 목록

- 머리 줄 높이 44. 보기 이름과 새 노트 버튼만 표시한다. 휴지통 머리에는 휴지통 그림이 있고 새 노트 버튼은 없다. 삭제된 제목은 보조 글자색이다.
- 줄 높이 `library-row-h` 47, 왼쪽 20, 오른쪽 14. 제목은 Pretendard 14, 굵기 450, `row-title`. 제목이 없으면 본문 첫 줄을 표시 제목으로 쓰고 둘째 줄 이후를 아래 줄에 쓴다. 저장된 노트 제목은 바꾸지 않는다. 대체 제목과 아래 줄은 편집기 파서가 보이는 본문만 사용한다. 본문까지 비면 보통 굵기 400의 `제목 없음`과 `text-2`를 쓴다.
- 아래 줄은 Pretendard 12.5, `text-3`, 한 줄과 끝 말줄임이다. 본문 첫머리가 비었을 때만 `투두 1개 남음` 같은 남은 개수를 쓴다. 본문이 있으면 투두 요약을 덧붙이지 않는다. 아래 줄이 비면 제목은 세로 가운데다.
- 오른쪽은 투두가 있는 노트만 완료/전체 수를 본문 글꼴 12pt, text-3, 같은 폭 숫자로 표시한다. 선택과 호버 바탕은 줄 안쪽의 둥근 칸이다.
- 한 번 클릭은 선택, 더블 클릭과 Return은 노트 열기다. 휴지통은 복원 후 연다. 포커스 링은 없다.
- 노트 도움말과 일정 상세는 저장된 상대/절대 날짜 표시를 따른다(D-087). 사이드바의 시작 시각 축약은 D-125를 따른다.
- 빈 목록에는 검색 지우기, 전체 노트 또는 새 노트 가운데 가능한 동작 하나만 둔다.

목록은 고정됨, 오늘, 어제, 이전 7일, 이전 30일, 연월 순서다. 날짜 묶음은 마지막 수정 날짜를 기준으로 하며 동률은 노트 ID 순서다. 보관함과 휴지통에서는 날짜로만 묶는다.

### 9.3 보관과 복원

- 노트 더 보기와 목록의 문맥 메뉴에서 보관함으로 옮기거나 되돌린다. 보관 상태는 노트 머리의 선택적 archived 참거짓 값으로 저장한다. 체크 완료만으로 보관하지 않는다. 보관하면 일반 보기, 고정됨, 노트 찾기와 빠른 캡처의 추가 목적지에서 제외한다.
- 옛 월별 아카이브 기준일은 최초 전환 시 한 번 저장한다. 필드가 없는 파일은 그때의 경계로 읽고, 되돌리기는 명시적인 false로 남긴다. 기존 본문, 알 수 없는 머리 줄과 파일 위치는 보존한다.
- 오늘 보기는 오늘 생성한 노트와 오늘 리마인더 노트의 합집합이다. 같은 노트는 한 번만 센다.
- 검색은 현재 보기의 제목, 본문을 대소문자 구별 없이 찾는다.
- 스페이스 삭제는 확인 후 노트의 소속만 해제한다. 휴지통 노트는 복원할 때 삭제된 스페이스 연결을 해제한다.
- 휴지통도 한 번 클릭은 선택만 한다. 더블 클릭, Return과 '되돌리기'는 복원 후 노트를 연다. 기존 ID 충돌, 저장 실패는 오류로 알리고 덮어쓰지 않는다.
- '리마인더 있는 노트' 보기에는 지난 값도 포함한다(D-052).
- 첫 보기는 오늘이다. 마지막 보기와 보일 보기, 열 때 보여 줄 곳은 `state/library.json`에 저장한다.
- 처음 켤 때 복원할 노트가 없으면 라이브러리가 열린다. 실행 중 다시 열거나 앱을 전환하면 라이브러리가 앞으로 온다(D-101). 라이브러리 머리의 AI, 설정은 연결 전까지 숨긴다.
- 휴지통 30일은 임시 값이며 삭제 시각 저장과 자동 비우기는 아직 구현하지 않는다(D-014, D-052).
