## 11. 에이전트 (화면 5)

화면 5의 옛 AI 패널(오른쪽에 붙는 430pt 패널, 도구 내역, 후보 상자, 머리 줄의 에이전트 목록)은 따르지 않는다. 에이전트 시안 최종판(2026-11-23)으로 대체했다(D-190~D-202).

| 무엇 | 파일 |
| --- | --- |
| 실행기, 연결, 로그인, 모델 메뉴(구현됨) | 이 파일의 아래 절 |
| 막대의 두 모드, 에이전트 창, 얼굴, 진행 표시, 에이전트 색, 점, 막혔을 때, 새 요소 표, 단계 | `11a-agent-surfaces.md` |
| 제안: 반영 방식, 미리보기, 버튼 자리, 제안 페이지 | `11b-agent-suggestions.md` |
| 루틴, 메모리, 기억 정리, 선제 알림 | `11c-agent-routines-memory.md` |

요청 막대와 에이전트 창이 이 실행기를 사용한다. 제안, 루틴과 메모리 화면은 후속이다.


### G0 실행기 계약

- 구독 연결은 엔진별 Float 전용 폴더로 로그인한다. 저장 위치는 `StoreLocation.stateDirectory/agents/claude`와 `agents/codex`다. Claude는 `auth status --json`에서 로그인 여부, 방식, 이메일, 요금제, 세부 등급, 만료를 읽는다. 이메일 원문은 연결 화면 메모리에만 둔다. Codex의 로그인 여부와 방식은 `login status`를 따른다. Float 전용 auth.json의 ID 토큰에서 읽을 수 있는 이메일과 요금제만 상세에 추가한다.
- 실행마다 빈 작업 폴더와 최소 환경을 만든다. Claude는 B3의 다섯 환경변수, 빈 설정 소스, 엄격한 Float MCP 설정, 빈 내장 도구 목록, 두 읽기 도구 허용, 슬래시 명령 차단, dontAsk, 세션 저장 해제를 사용한다. `stream-json`의 부분 메시지, 결과, 비용과 한도 이벤트를 읽는다.
- Claude의 첫 init에서 두 도구 이름, 연결된 float 서버 한 개, 빈 스킬과 명령, 내장 경로의 `cc-plugin-*`만 허용한다. 필드 누락, 추가 도구, 잘못된 서버가 있으면 그 실행의 그룹을 종료하고 위반 필드를 반환한다.
- Codex는 전용 CODEX_HOME과 별도의 빈 사용자 홈, 읽기 전용 샌드박스, 사용자 설정과 규칙 무시, 임시 실행, 닫힌 stdin을 사용한다. Float MCP의 도구 이름을 제한하고 셸, 앱, 훅, 플러그인, 웹 검색을 끈다. Codex의 JSONL에는 Claude식 init 목록이 없다. 실행 중 관측한 도구 이벤트도 검사한다. CLI가 실제 모델이나 비용을 주지 않으면 값을 비워 둔다.
- 실행 기록은 `stateDirectory/agent-usage/<실행 UUID>.json`에 원자적으로 저장한다. 시작 시각, 경과 시간, 엔진, 요청 모델, 확인된 모델, 결과 상태, 제공된 토큰 수와 USD 비용만 남긴다. Claude 입력 합계에는 캐시 생성과 읽기가 포함된다. 중단 전 사용량이 없으면 값도 비어 있다.
- G0의 MCP는 노트 목록과 원문 읽기만 제공한다. 노트와 일정 변경은 후속 단계에서 사용자가 제안을 확인한 뒤 앱이 반영한다.

### 에이전트 연결과 만료

설정을 열면 설치와 로그인 상태를 확인한다. 첫 화면은 연결된 에이전트만 선택할 수 있다. 기본 에이전트는 Claude다. 모델 값 버튼은 왼쪽 체크 메뉴를 연다. Claude는 설정 창을 열 때 한 번 전용 CLI에 초기화 제어 요청만 보내 모델 목록을 받는다. 자동 뒤에 CLI 순서대로 모든 모델을 표시하고 선택한 value를 --model에 넘긴다. description을 U+00B7로 나눈 첫 조각이 displayName으로 시작하면 그 조각을, 그 밖에는 displayName을 메뉴와 값 버튼에 표시한다. 자동은 모델 인자를 생략하며 CLI의 기본 항목은 자동에 합친다. 선택지가 있을 때만 자동 아래에 구분선을 둔다. 성공한 목록에서 저장값이 사라지면 자동으로 전환해 저장한다. 실패하면 자동, Fable, Opus, Sonnet, Haiku로 돌아가고 저장값을 보존한다. 창을 닫으면 목록을 비운다(D-186). Codex는 CLI 기본 뒤에 전용 CODEX_HOME의 `codex debug models`에서 visibility가 list인 항목을 Codex가 매긴 우선순위 순서(priority 오름차순)로 앞 다섯 개 표시한다. 저장된 모델이 그 뒤에 있으면 여섯째 모델로 추가하고 체크한다(D-182). display_name을 보여 주고 slug를 -m으로 넘긴다. 설정을 열 때 한 번 조회하고 닫을 때 목록을 비운다. 조회 실패 시 CLI 기본만 보이고 저장값을 보존한다. 조회에 성공했을 때 저장한 slug가 표시 가능한 전체 목록에서 사라졌으면 CLI 기본으로 전환해 저장한다. 목록에는 로고, 이름, 회사, 상태와 꺾쇠를 둔다.

상세에서는 계정, 요금제, 로그인 방식을 읽기 전용으로 표시한다. 이메일은 전체를 표시하고 창을 닫을 때 메모리에서 지운다. 상세에서 연결하면 취소 가능한 브라우저 로그인 뒤 계정을 다시 확인한다. 연결된 상태의 로그아웃은 해당 전용 폴더의 CLI 명령을 실행한다.

CLI가 보고한 로그인 만료일이 지났거나 전용 폴더에 자격 파일 또는 과거 연결 표시가 있는데 로그인되지 않았으면 만료다. 사이드바 경고와 상세의 다시 로그인 배너를 보인다. 막힌 작업에서 만료가 확인되면 macOS 알림에 일 이름과 다시 로그인 동작을 붙인다. 같은 만료는 한 번만 알리고 재연결하면 초기화한다. 알림을 위한 주기 검사는 하지 않는다.

설치가 필요하면 공식 설치 명령을 노트 코드 블록 바탕에 표시한다. 복사 아이콘만 동작하며 아래에 다른 설치 방법 ↗ 글자 링크를 둔다. 정보 아이콘에 올리면 위쪽에 검은 툴팁과 꼬리가 나타난다. 설정 창이 다시 키 창이 될 때 설치 여부를 재확인한다.

### 대화 요청 실행 계약

전송 차례마다 설정의 제공자와 저장 모델을 읽는다. 전용 환경에서 계정을 확인하고 요청 하나에 Claude B3 또는 Codex 임시 exec 한 번을 쓴다. Claude에는 bare를 넘기지 않는다. 실행 파일 검색 폴더를 지정한 실행은 그 폴더에서만 찾는다. 지침, 대상 파일 이름, 최근 대화와 새 요청을 구분한다. 입력 예산에서 빠진 과거 메시지 수를 명시한다.

호출 ID가 맞는 성공한 읽기 결과만 실제 노트 ID와 대조해 링크한다. 진행의 경과 시간은 앱이 관측한 구간이다. 부분 답은 성공 시 최종 답으로 교체한다. 취소 시 그룹 회수와 사용량 기록을 마친 뒤 다음 실행을 시작한다. 사용량 파일 이름과 대화의 실행 ID가 같고, 요청과 답 원문과 계정 정보는 사용량 파일에 기록하지 않는다.
