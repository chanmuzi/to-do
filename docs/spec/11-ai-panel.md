## 11. AI 패널 (화면 5)

- 머리 줄: 별 모양 아이콘과 "에이전트"(13pt 굵기 650) / 오른쪽에 지금 에이전트 이름과 아래 꺾쇠(누르면 목록), 닫기 ×.
- 대화: 내 요청은 오른쪽 말풍선(`surface-3` 바탕, 모서리 12, 안쪽 6 11, 최대 너비 84%). 에이전트의 답은 왼쪽에 별 모양 아이콘(너비 22 칸)과 함께, 말풍선 없이.
- 도구 내역: 일하는 동안에는 펼쳐서 출처마다 한 줄(체크 또는 도는 아이콘, 출처 이름, "메일 14건"). 끝나면 "Gmail, Calendar, Notion 확인함" 한 줄로 접힙니다. 누르면 다시 펼쳐집니다. 12pt `text-3`. 도는 아이콘은 아이콘 자체를 중심으로 1초에 한 바퀴 돌고 체크 아이콘과 같은 세로선에 있습니다.
- 후보 상자: 누를 수 있는 것(체크, 제목 고치기, 추가)은 테두리 상자 하나 안에 모읍니다. 모서리 8, 1pt `outline`.
  - 후보 줄: 체크박스 / 제목(굵기 500)과 그 아래 출처 줄(12pt, 출처 아이콘과 근거 한 줄) / 오른쪽에 스페이스 아이콘과 날짜나 시간(D2Coding `fs-micro`).
  - 체크를 뺀 후보는 제목이 `text-2`입니다. 이미 있는 투두와 비슷하면 체크를 빼 두고 그 아래에 이유 한 줄과 "하나로 합치기" 링크를 둡니다.
  - 제목을 누르면 그 자리에서 고칩니다(상자 없이 커서만).
  - 상자 맨 아래 오른쪽에 "N개 추가" 버튼. N은 체크한 개수입니다.
- 입력 칸: 높이 32, 1pt `outline`, 자리 글자 "에이전트에게 요청하기". 오른쪽에 위쪽 화살표 아이콘 버튼. 글자가 없으면 `text-3`, 있으면 `text`.
- 에이전트 목록: 이름은 Claude와 Codex입니다. 지금 쓰는 것 왼쪽에 체크. 쓸 수 있는 것은 그대로. 연결이 필요한 것은 `text-3`로 흐리게 하고 오른쪽에 플러그 아이콘. 흐린 줄을 누르면 연결 안내를 엽니다.


### G0 실행기 계약

- 구독 연결은 엔진별 Float 전용 폴더로 로그인한다. 저장 위치는 `StoreLocation.stateDirectory/agents/claude`와 `agents/codex`다. Claude는 `auth status --json`에서 로그인 여부, 방식, 이메일 도메인, 요금제, 세부 등급, 만료를 읽는다. 이메일 원문은 연결 화면 메모리에만 둔다. Codex는 `login status`가 제공하는 로그인 여부와 방식만 표시한다.
- 실행마다 빈 작업 폴더와 최소 환경을 만든다. Claude는 B3의 다섯 환경변수, 빈 설정 소스, 엄격한 Float MCP 설정, 빈 내장 도구 목록, 두 읽기 도구 허용, 슬래시 명령 차단, dontAsk, 세션 저장 해제를 사용한다. `stream-json`의 부분 메시지, 결과, 비용과 한도 이벤트를 읽는다.
- Claude의 첫 init에서 두 도구 이름, 연결된 float 서버 한 개, 빈 스킬과 명령, 내장 경로의 `cc-plugin-*`만 허용한다. 필드 누락, 추가 도구, 잘못된 서버가 있으면 그 실행의 그룹을 종료하고 위반 필드를 반환한다.
- Codex는 전용 CODEX_HOME과 별도의 빈 사용자 홈, 읽기 전용 샌드박스, 사용자 설정과 규칙 무시, 임시 실행, 닫힌 stdin을 사용한다. Float MCP의 도구 이름을 제한하고 셸, 앱, 훅, 플러그인, 웹 검색을 끈다. Codex의 JSONL에는 Claude식 init 목록이 없다. 실행 중 관측한 도구 이벤트도 검사한다. CLI가 실제 모델이나 비용을 주지 않으면 값을 비워 둔다.
- 실행 기록은 `stateDirectory/agent-usage/<실행 UUID>.json`에 원자적으로 저장한다. 시작 시각, 경과 시간, 엔진, 요청 모델, 확인된 모델, 결과 상태, 제공된 토큰 수와 USD 비용만 남긴다. Claude 입력 합계에는 캐시 생성과 읽기가 포함된다. 중단 전 사용량이 없으면 값도 비어 있다.
- G0의 MCP는 노트 목록과 원문 읽기만 제공한다. 노트와 일정 변경은 후속 단계에서 사용자가 제안을 확인한 뒤 앱이 반영한다.
