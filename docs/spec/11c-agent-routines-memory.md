## 11c. 루틴, 메모리, 선제 알림

구현 상태: 아직 구현하지 않았다. 루틴과 지우기 확인은 2단계, 메모리의 지침 문서는 1단계, 기억과 변경 기록, 기억 정리, 선제 알림은 3단계다(11a의 단계 절).

근거는 에이전트 시안 최종판(2026-11-23)이다(D-195~D-200).

### 루틴

정해진 때에 에이전트가 알아서 도는 일이다. 이름은 루틴이다.

- 목록: 페이지 이름과 같은 묶음 머리는 두지 않고 줄부터 시작한다. 줄에는 이름, 마지막 실행 한 줄, 오른쪽에 주기를 둔다. 줄에 올리면 지금 실행과 더 보기가 나타나고 꺼 둔 것은 오른쪽에 `꺼짐`이다. `새 루틴`은 머리 오른쪽이다.
- 빈 화면에만 예시(이름과 한 줄 설명)를 보인다. 누르면 그 내용이 채워진 만들기가 열린다.
- 만들기: 양식은 이름, 시킬 일, 주기만 받는다. `다음`을 누르면 에이전트가 요약(언제, 읽는 것, 만드는 것, 결과, 하지 않는 것)을 만들어 보이고, 확인해야 저장된다. 대화에서 말로 시키면 빠진 것만 되묻고 같은 요약 카드를 낸다.
- 테스트: 요약 카드의 테스트를 누르면 노트를 바꾸지 않고 무엇이 나올지 보인다. 설명은 제목 옆 정보 아이콘의 툴팁으로만 둔다.
- 실행: 루틴이 돌 때마다 대화 하나가 생긴다. 이어서 말할 수 있다. 혼자 정할 수 없으면 멈추고 macOS 알림으로 알린다. 답하면 이어서 돈다.

### 루틴 하나의 화면

- 요약 상자(`surface-2`, 모서리 8pt, 안쪽 12와 16pt)의 머리에 이름과 켜고 끄는 스위치를 둔다.
- 요약 아래에 구분선 하나(`line`, 1pt, 상자 안쪽 폭 전체, 요약 아래 12pt).
- 구분선 아래 오른쪽에 아이콘 버튼 줄(구분선 아래 8pt). 왼쪽부터 지금 실행, 테스트, 고치기, 세로 선(높이 14pt), 지우기. 버튼 24pt, 그림 14pt, 사이 2pt.
- 아이콘 버튼에 툴팁을 두지 않는다. 올리면 `hover` 바탕만 깔린다. 지우기는 올렸을 때만 `warn` 색이다. 접근성 라벨(지금 실행, 테스트, 고치기, 지우기)은 둔다.
- 고치기를 누르면 요약이 그 자리에서 고치는 칸이 된다. 구분선 아래 줄은 `에이전트와 고치기`(왼쪽), `취소`, `저장`(오른쪽)으로 바뀐다.
- 상자 아래에 지난 실행 목록을 둔다. 줄을 누르면 그 실행의 대화가 열린다.

### 지우기 확인 팝오버

- 시스템 확인 창을 쓰지 않는다. 지우기 아이콘 아래에 작은 팝오버를 붙인다(오른쪽 끝을 아이콘에 맞춤, 아이콘 아래 4pt). 값은 11a의 `confirm-popover`다.
- 글: `루틴을 삭제할까요?`, 아래에 `이미 받은 제안과 노트는 그대로 남습니다.`. 버튼은 오른쪽 아래에 `취소`, `삭제`. 삭제는 글자만 `warn`이고 바탕과 테두리는 취소와 같다.
- Esc와 바깥을 누르는 것은 취소다. Return은 어느 버튼에도 걸지 않는다.
- 삭제하면 루틴 목록으로 돌아간다. 되돌리기 알림은 없다. 그 루틴의 지난 실행 대화도 함께 지운다.
- 스페이스 지우기도 같은 팝오버를 쓴다(9장).

### 메모리

사이드바에 메모리 한 줄을 둔다. 본문 맨 위 세그먼트로 지침과 기억을 오간다.

- 지침: 마크다운 문서 하나다. Float 편집기 그대로 고친다. 에이전트는 사용자가 앞으로 이렇게 해 달라고 시킬 때만 지침 고치기를 제안하고, 받아야 바뀐다. `변경 기록`은 머리 오른쪽의 시계다.
- 기억: 한 줄에 하나다. 에이전트가 적은 것과 내가 적은 것을 묶음으로 나눈다. 줄을 누르면 아래로 펼쳐져 근거(무엇을 보고 적었는지)와 그 줄의 버튼(`대화에서 보기`, `고치기`, `지우기`)을 오른쪽 아래에 둔다. 머리 오른쪽의 시계는 변경 기록, +는 기억 추가다. 기억 줄에 올리면 더 보기가 나타난다.
- 에이전트는 기억을 승인 없이 적고, 바뀐 직후 짧은 알림 한 줄에 `보기`와 `되돌리기`를 둔다. `보기`를 누르면 메모리 페이지가 열리고 바뀐 줄이 잠깐 형광펜 색으로 표시된다.
- 변경 기록: 지침과 기억의 변경을 날짜로 묶은 한 목록이다. 고른 변경의 바뀐 것과 근거를 오른쪽에 보이고, `대화에서 보기`, `확인하러 가기`, `되돌리기`를 오른쪽 아래에 둔다.
- 새로 적힌 기억 줄과 기억 세그먼트에는 점이 붙는다(11a). 지침에는 붙지 않는다.

### 기억 정리

- 겹치는 기억을 합치고 낡은 기억을 지우는 일이다. 변경 기록에 합치기 전과 뒤의 줄을 남긴다.
- 도는 때: 아침과 저녁, 그리고 노트를 많이 고친 뒤(사용자 확정). 시각과 기준 숫자는 20장 15번의 임시 값을 쓴다.
- 지난번 뒤로 새 기억이 없으면 모델을 부르지 않고 건너뛴다. 한 번 돌면 얼마 동안 다시 돌지 않는다(20장 15번).
- 루틴 목록의 보통 줄로 보인다. 꼬리표를 붙이지 않는다. 스위치로 끈다. 지금 실행으로 언제든 돌린다.
- 도는 동안 얼굴은 기억 정리 중 상태다.

### 선제 알림

일정이나 리마인더 앞에 에이전트가 먼저 알리는 것이다.

- 모습: 화면 구석 단추의 얼굴이 볼 것 있음이 되고 그 왼쪽에 말풍선(11a의 `bubble`)이 뜬다. 포커스를 가져가지 않는다.
- 말풍선에는 알릴 글과 그 아래 노트로 가는 줄(예: 회의 노트 열기)을 둔다.
- 화면 구석 단추가 켜져 있을 때만 쓸 수 있다.

아래는 시안에서 임시로 정한 것이다. 구현 전에 다시 확인할 수 있다(D-200).

- 뜨는 때는 20장 16번의 임시 값을 쓴다. 소리는 내지 않는다.
- 말풍선의 글을 누르면 에이전트 창이 그 내용의 대화로 열린다. 노트로 가는 줄을 누르면 그 노트가 뜬다.
- 말풍선에 올리면 오른쪽 위에 닫기 아이콘 버튼이 보인다. 닫지 않아도 일정이 시작하면 사라진다. 사라진 뒤에도 대화 페이지에 줄로 남고 점이 붙는다.
- 여러 개가 겹치면 가장 이른 일정의 것 하나만 보이고 아래에 몇 개 더 있는지 적는다. 닫거나 누르면 다음 것이 나온다. 쌓아 올리지 않는다.
- 설정의 에이전트 표시 카드에 `일정 전에 먼저 알리기` 스위치를 둔다. 화면 구석 단추를 끄면 함께 꺼진다.
- 모델은 아침에 그날 일정을 한꺼번에 준비할 때 한 번 부른다. 준비한 뒤 일정이 바뀌면 한 번 더 부른다. 시각에 맞춰 띄우는 것은 앱이 한다.
