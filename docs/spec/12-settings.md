## 12. 설정 (화면 6)

앱 메뉴, 메뉴 막대, Dock, 라이브러리의 설정과 ⌘,는 일반 화면을 연다. 도움말과 ⌘/는 같은 창의 단축키 화면을 연다. 선택은 즉시 저장하고 열린 창에도 적용한다.

설정 창은 700 × 540pt다. 신호등을 숨기고 오른쪽 위 X(칸 22, 그림 10), Esc 또는 ⌘W로 닫는다. 바탕을 끌어 옮긴다. 사이드바는 너비 184, 행 높이 26, 글자 13, SF Symbol 14다. 선택은 회색 6%와 굵기 500으로 표시한다. 일반, 모양, 편집기 다음과 일정과 캘린더, 단축키 다음에 선을 둔다. 연결 머리 아래 AI 비서가 오고, 맨 아래 선 밑에 앱 정보를 둔다. 구분선은 좌우 8, 위아래 6을 띄운다.

오른쪽은 제목 17/600, 설명 12, 구획 이름 11/500, 카드 안 이름 13과 설명 11을 쓴다. 보조 설명은 text-3다. 카드는 surface-2, 모서리 10, 좌우 12이며 행은 최소 40이다. 행 사이는 line 실선이다. 현재 값은 12pt 팝업, 호버 바탕은 좌우 6pt다(D-116). 스위치는 30 × 16이다.

| 화면 | 항목과 동작 |
| --- | --- |
| 일반 | 메뉴 막대 아이콘 스위치 |
| 모양 | 시스템, 라이트, 다크. 본문 12~17pt(기본 14pt) 숫자 조절, 줄 간격과 스페이스 표시 팝업 |
| 편집기 | 코드 글자색, 체크박스, 입력 중 글자, 서식 표시줄 팝업. 날짜 알아보기 스위치 |
| 일정과 캘린더 | 상대와 절대 날짜, 영문과 한글 오전/오후와 24시간제. 종류별로 권한을 요청하거나 시스템 설정을 열고, 허용하면 기본 캘린더와 미리 알림 목록을 선택 |
| 단축키 | spec 13의 읽기 전용 표 |
| AI 비서 | 엔진과 계정 행의 현재 값과 꺾쇠로 하위 화면을 연다. 제목 위의 AI 비서 버튼으로 돌아온다. 모델은 자동, opus, sonnet, haiku |
| 앱 정보 | 앱 버전, 기본값으로 확인 시트. 확정하면 앱 설정과 예전 테마 덮어쓰기를 초기화하고 노트, 일정, 캘린더 권한과 엔진 인증은 보존 |

서식 표시줄 저장값은 always, editing(기본), hidden이다. 입력 중 글자는 표시 없음(기본), 옅은 밑줄이다. 옛 저장 파일도 새 항목의 기본값으로 읽는다. 캘린더 팝업은 계정별 대상, 색 점, 현재 체크, 마지막 시스템 기본값을 유지한다.

G2의 예약과 제안, G3의 Google, Notion, 네이버 연결은 기능을 제공할 때 추가한다. 테마 프리셋, 강조색과 형광펜, 노트 색 팔레트, 본문 글꼴 가족, 창 투명도와 흐림, 테마 JSON 가져오기와 내보내기도 후속이다.
