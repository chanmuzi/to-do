## 12. 설정 (화면 6)

앱 메뉴의 설정..., 라이브러리 머리의 설정 버튼, 메뉴 막대 메뉴, Dock 메뉴가 같은 창을 연다. ⌘,는 마지막으로 본 구획을 열고 ⌘/는 단축키 구획으로 이동한다. 마지막 구획은 실행 중에 기억한다. 저장이 성공하면 열린 화면에도 즉시 적용한다(D-098).

| 구획 | 항목 | 표시와 저장 |
| --- | --- | --- |
| 모양 | 라이트, 다크, 시스템 | 기본은 시스템. 시스템 모드는 macOS의 모양 변경을 따라간다 |
| 모양 | 본문 글꼴 크기, 줄 높이 | 각각 12~16pt, 18~32pt. 예전 테마 덮어쓰기 값으로 시작하고 새 선택만 앱 설정에 저장한다 |
| 모양 | 스페이스 표시 | 아이콘, 아이콘과 이름, 이름 |
| 편집기 | 인라인 코드, 체크박스 | 강조 또는 흑백, 상자 또는 대괄호 |
| 편집기 | 본문과 제목에서 날짜 알아보기 | 기본은 켜짐. 끄면 떠 있는 노트에서도 밑줄과 Tab 받기가 사라진다. 시계 창과 빠른 캡처는 계속 날짜를 읽는다 |
| 예정 | 날짜와 시간, 리마인더 표시 | 상대 또는 절대 날짜, 시간 또는 남은 시간 또는 아이콘, 영문 오전/오후 또는 한글 오전/오후 또는 24시간제 |
| 예정 | 기본 캘린더, 기본 미리 알림 목록 | 권한과 쓰기 가능한 대상에 따라 연결, 시스템 설정, 선택 메뉴를 표시한다. 자세한 동작은 21장 |
| 앱 | 메뉴 막대 아이콘 표시 | 꺼도 앱 메뉴, Dock, 단축키를 쓴다 |
| 단축키 | 13장 전체 표 | 구역별 동작과 키를 읽을 수 있다 |

모양과 편집기 오른쪽에 노트 미리 보기 두 장을 둔다. 선택 배경은 `selected`, 선택 굵기는 `fw-selected`, 호버는 `hover`다. 컨트롤 높이는 `ctl-h`이고 설정 치수는 `component.settings-*`에 둔다. 스위치는 켜짐과 꺼짐을 색과 손잡이 위치로 구분한다. 캘린더는 이름과 원래 색으로 구분한다.

후속 범위는 프리셋 선택과 저장, 강조색과 기본 형광펜 선택, 노트 색 팔레트 편집, 본문 글꼴 가족, 창 투명도와 흐림, 테마 JSON 내보내기와 가져오기, 테마 초기화다. 해당 기능을 구현할 때 컨트롤을 추가한다.
