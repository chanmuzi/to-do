## 12. 테마 설정 (화면 6)

왼쪽은 설정 항목, 오른쪽(너비 330)은 미리 보기 노트 두 장입니다. 바꾸면 미리 보기와 떠 있는 노트에 바로 반영됩니다.

| 구획 | 항목 | 컨트롤 |
| --- | --- | --- |
| | 프리셋 | 칩(기본, 그린, 앰버 등)과 "현재 설정 저장"(+ 아이콘, 테두리 없음). 고르면 아래 값이 모두 바뀜 |
| 색과 글꼴 | 모드 | 라이트, 다크, 시스템 |
| | 강조색 | 색 칸 다섯(14pt). 옆에 값과 이름(D2Coding) |
| | 형광펜 | 노랑, 회색, 로즈, 블루. 고른 것이 기본 형광펜 색 |
| | 노트 색 | 팔레트: 없음 + 여덟 + 추가. 누르면 미리 보기 노트에 입혀 봄. 여기서 팔레트를 고치고 더함 |
| | 본문 글꼴 | 글꼴 고르기와 크기(12부터 16) |
| 창 | 투명도 | 슬라이더 30%부터 100%, 기본 92% |
| | 배경 흐림 | 스위치 |
| 표시 | 스페이스 | 아이콘, 아이콘+이름, 이름 |
| | 리마인더 | 시간, 남은 시간, 아이콘 |
| | 시간 형식 | 3:00 PM, 오후 3:00, 15:00 |
| | 체크박스 | 상자, [ ] 대괄호 |

- 선택 칸: 1pt `line` 테두리 안에서 고른 칸만 `surface-3` 바탕, `text`, 굵기 600. 칸 높이 18, 전체 높이 `ctl-h`(22).
- 버튼: 높이 22, 1pt `line` 테두리, `text-2`. 올리면 `hover` 바탕에 `text`. 주된 버튼("N개 추가", "완료")은 `surface-3` 바탕, `text`, 굵기 600, 테두리 없음.
- 구획 이름: 11.5pt 굵기 700. 항목 이름: `text-2`, 너비 76 칸.
