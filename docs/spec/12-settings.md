## 12. 설정 (화면 6)

앱 메뉴의 설정..., 라이브러리 머리의 설정 버튼, 메뉴 막대 메뉴, Dock 메뉴가 같은 창을 연다. ⌘,는 설정을 열고 ⌘/는 단축키 표를 연다. 저장한 선택은 열린 창에 즉시 적용한다.

설정 창은 모양, 편집기, 예정, 앱 순서로 이어지는 한 화면이다. 구획 제목과 가로 구분선, 왼쪽 이름 열과 그 옆 조작 열을 둔다. 세그먼트는 1pt 테두리와 선택 바탕, 스위치는 단색 채움과 손잡이를 쓴다.

| 구획 | 항목 | 값과 동작 |
| --- | --- | --- |
| 모양 | 화면, 본문 글자, 스페이스 | 시스템, 라이트, 다크. 본문 12~17pt, 기본 14pt. 줄 높이와 스페이스 표시 선택 |
| 편집기 | 코드 글자색, 체크박스, 날짜 알아보기 | 강조 또는 흑백, 상자 또는 대괄호, 날짜 인식 스위치 |
| 편집기 | 입력 중 글자 | 표시 없음(기본), 옅은 밑줄. 제목과 본문 조합에 적용 |
| 편집기 | 서식 표시줄 | 항상, 편집할 때(기본), 숨김. 저장값은 `always`, `editing`, `hidden` |
| 예정 | 날짜 표시, 시간 형식 | 상대와 절대 날짜, 영문과 한글 오전/오후와 24시간제 |
| 예정 | 캘린더 | 미결정이면 연결, 거부하면 시스템 설정 열기. 허용한 종류는 기본 캘린더와 미리 알림 팝업으로 표시 |
| 앱 | 메뉴 막대 아이콘, 단축키 | 스위치와 단축키 표 열기 |

팝업 값의 첫 글자는 세그먼트 첫 글자와 맞추고 좌우 6pt 바깥까지 호버를 칠한다. 펼치면 너비 210pt 메뉴에 26pt 항목과 계정 머리, 색 점, 현재 선택 체크, 마지막 시스템 기본값을 둔다.

맨 아래 밑줄 링크 **기본값으로**는 확인 시트를 연다. 되돌리기를 확정하면 앱 설정과 예전 테마 덮어쓰기를 초기화한다. 노트, 일정과 캘린더 권한은 보존한다. 예전 저장 파일에 서식 표시줄과 입력 중 글자 값이 없으면 각 기본값을 쓴다.

후속 범위는 프리셋 선택과 저장, 강조색과 기본 형광펜 선택, 노트 색 팔레트 편집, 본문 글꼴 가족, 창 투명도와 흐림, 테마 JSON 내보내기와 가져오기다. 해당 기능을 구현할 때 컨트롤을 추가한다.
