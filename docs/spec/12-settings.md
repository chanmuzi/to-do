## 12. 설정 (화면 6)

앱 메뉴, 메뉴 막대, Dock, 라이브러리와 ⌘,는 일반 화면을 연다. 도움말과 ⌘/는 같은 창의 단축키 화면을 연다. 값을 바꾸면 저장하고 열린 창에 즉시 적용한다.

창은 700 × 540pt다. 닫기와 최소화 신호등을 쓰고 확대는 흐리게 표시한다. 빨간 단추, Esc, ⌘W로 닫는다. 빈 바탕을 끌어 창을 옮긴다. 위 52pt 줄에 제목(15pt, 600)을 둔다.

사이드바 폭은 200pt다. 행은 28pt, 배경은 위아래 1pt 안쪽이다. 선택은 selected와 굵기 500, 호버는 hover다. 에이전트의 sparkles 그림은 오른쪽으로 1.5pt 보정한다. 일반, 모양, 편집기 다음과 일정과 캘린더, 단축키 다음에 선을 둔다. 연결 머리 아래에 에이전트를 두고 만료 시 오른쪽에 경고를 보인다. 오른쪽 아래 버전은 번들의 표시 버전을 읽는 글자다.

카드는 surface-2, 반경 10pt, 좌우 여백 12pt, 행 높이 36pt다. 짧은 선택지는 세그먼트로 두고 선택한 칸에만 밝은 바탕을 쓴다. 에이전트, 모델, 캘린더 값 버튼은 불투명한 surface 바탕의 Float 메뉴를 열며 현재 값 왼쪽에 체크한다. 값 버튼의 바탕 오른쪽 끝을 다른 조작과 맞춘다. 동작 버튼은 흰 바탕에 옅은 테두리를 두고 되돌리기는 warn 글자를 쓴다.

| 화면 | 항목과 동작 |
| --- | --- |
| 일반 | 메뉴 막대 아이콘 스위치. 아래 별도 카드의 ‘되돌리기’를 누르면 ‘모든 설정을 되돌릴까요?’ 확인 창이 뜬다. 취소하거나 설정과 기존 테마 덮어쓰기를 초기화한다. 노트와 에이전트 연결은 보존한다. |
| 모양 | 시스템, 라이트, 다크. 본문 12~17pt(기본 14pt) 눈금 슬라이더 양끝에 작은 ‘가’, 큰 ‘가’를 둔다. 줄 간격, 스페이스 표시를 고른다. |
| 편집기 | 코드 글자색, 체크박스(상자 그림과 대괄호), 입력 중 글자, 서식 표시줄 세그먼트, 날짜 알아보기 스위치. |
| 일정과 캘린더 | 날짜와 시간 표시 형식을 고른다. 권한에 따라 연결하거나 시스템 설정을 연다. 저장 위치 메뉴 맨 위 ‘캘린더 앱 기본값’ 옆에 현재 대상 이름을 옅게 표시한다. 기본값을 고르면 저장 ID는 nil이다. |
| 단축키 | spec 13의 읽기 전용 표. 13pt 시스템 글꼴의 회색 값을 오른쪽에 정렬한다. |
| 에이전트 | 사용할 에이전트와 모델, 제공자별 연결 상태를 표시한다. 52pt 행 전체를 누르면 상세로 이동한다. 한 줄 이동 줄의 호버 높이는 30pt다. 두 줄 이동 줄은 줄 높이에서 위아래 4pt씩 빼므로 이름과 회사를 표시하는 52pt 행의 호버 높이는 44pt다. 반경은 6pt이고 내용보다 양옆으로 6pt씩 넓다. 구분선은 카드 좌우에서 12pt씩 들인다(D-185). Claude 모델 메뉴는 자동과 구분선 뒤에 CLI 순서대로 모든 모델을 보여 준다. description을 U+00B7로 나눈 첫 조각이 displayName으로 시작하면 그 조각을, 그 밖에는 displayName을 메뉴와 값 버튼에 표시한다. 기본 항목은 자동과 합치고, 조회 실패 시 고정 별칭 메뉴를 사용한다(D-186). Codex 모델 메뉴는 CLI 기본, 구분선, Codex가 매긴 우선순위 순서의 앞 다섯 모델을 표시한다. 저장된 모델이 이후 순서면 끝에 추가하고 체크한다. 전체 목록에서 사라졌으면 CLI 기본으로 전환해 저장한다. 조회 실패 시 CLI 기본만 표시하고 저장값은 보존한다(D-182). 계정과 연결 흐름은 spec 11을 따른다. |

모양과 편집기 맨 위에는 340pt 노트 미리보기를 둔다. 미리보기는 하나의 접근성 이미지로 읽히며 호버, 클릭, 키보드 포커스를 받지 않는다. 기본 본문 14pt, 줄 높이 24pt, 체크박스 14pt다. 바뀐 부분의 테두리는 0.6초 후 사라진다. 동작 줄이기에서는 테두리를 생략한다.

서식 표시줄 저장값은 always, editing(기본), hidden이다. 입력 중 글자는 표시 없음(기본), 옅은 밑줄이다. 옛 파일에서 새 항목이 빠지면 기본값으로 읽는다.

에이전트 화면에는 에이전트 표시 카드(노트에 표시, 화면 구석 단추, 일정 전에 먼저 알리기)와 반영 방식 카드(종류별 승인 후와 바로, 11b)를 더한다. 미구현이다: 표시 카드의 앞 두 줄과 반영 방식 카드는 11a의 단계 1, 종류별 바로 반영은 단계 2, 일정 전에 먼저 알리기는 단계 3. Google, Notion, 네이버 연결은 그 뒤에 기능을 제공할 때 추가한다(D-202). 테마 프리셋, 강조색과 형광펜, 노트 색 팔레트, 본문 글꼴 가족, 창 투명도와 흐림, 테마 JSON 가져오기와 내보내기도 후속이다.
