## 13. 단축키 (화면 7)

단축키는 이 표에서만 보여 줍니다. 어디서나 쓰는 넷은 사용자가 바꿀 수 있어야 합니다.

**어디서나 (다른 앱을 쓰는 중에도. 모두 바꿀 수 있음)**

| 동작 | 키 |
| --- | --- |
| 빠른 캡처 | ⌃ ⌥ N |
| 떠 있는 노트 모두 숨기기, 다시 보이기 | ⌃ ⌥ H |
| 라이브러리 | ⌃ ⌥ L |
| AI 패널 | ⌃ ⌥ A |

**빠른 캡처 바**

| 동작 | 키 |
| --- | --- |
| 추가 | ↵ |
| 새 노트로 띄우기 | ⌘ ↵ |
| 스페이스 바꾸기 | ⇥ |
| 리마인더 직접 고르기 | ⌘ R |
| 닫기 | esc |

**AI 패널**

| 동작 | 키 |
| --- | --- |
| 항목 이동 | ↑ ↓ |
| 체크, 체크 해제 | Space |
| 제목 고치기 | ↵ |
| 모두 체크 | ⌘ A |
| 체크한 항목 추가 | ⌘ ↵ |
| 닫기 | esc |

**노트 창**

| 동작 | 키 |
| --- | --- |
| 새 노트 | ⌘ N |
| 노트 찾기 | ⌘ P |
| 더 보기 메뉴 | ⌘ K |
| 다음 노트로 | ⌘ ` |
| 제목 고치기 | ⇧ ⌘ T |
| 항상 위에 고정 켜기, 끄기 | ⇧ ⌘ P |
| 리마인더 설정 | ⌘ R |
| 스페이스 옮기기 | ⇧ ⌘ M |
| 노트 안에서 찾기 | ⌘ F |
| 전체 검색 | ⇧ ⌘ F |
| 창 닫기 (노트는 남음) | ⌘ W |
| 설정 | ⌘ , |
| 이 단축키 표 | ⌘ / |

**노트 찾기**

| 동작 | 키 |
| --- | --- |
| 항목 이동 | ↑ ↓ |
| 열기 | ↵ |
| 닫기 | esc |

**라이브러리**

| 동작 | 키 |
| --- | --- |
| 선택한 줄 열기(휴지통은 복원 후 열기) | ↵ |
| 목록 선택 이동 | ↑ ↓ |
| 컨트롤 사이 이동 | ⇥ / ⇧ ⇥ |

**편집**

| 동작 | 키 |
| --- | --- |
| 들여쓰기 (하위 계층으로) | ⇥ |
| 내어쓰기 | ⇧ ⇥ |
| 투두로 바꾸기 | ⇧ ⌘ 9 |
| 완료 표시 | ⌘ ↵ |
| 줄 위로, 아래로 옮기기 | ⌃ ⌘ ↑ ↓ |
| 접기, 펼치기 | ⌥ ⌘ [ ] |
| 제목 1, 2, 3 | ⌥ ⌘ 1 2 3 |
| 굵게 | ⌘ B |
| 취소선 | ⇧ ⌘ X |
| 형광펜 (다시 누르면 다음 색) | ⇧ ⌘ H |
| 인라인 코드 | ⌘ E |
| 코드 블록 | ⌥ ⌘ C |
| 링크 | ⌘ L |

**마크다운으로 입력**

| 동작 | 키 |
| --- | --- |
| 제목 1, 2, 3 | # ## ### |
| 글머리표 | - |
| 투두 | [] 또는 [ ] |
| 토글 | > |
| 인용문 | " 또는 \| |
| 굵게 | **글자** |
| 취소선 | ~~글자~~ |
| 형광펜 | ==글자== |
| 인라인 코드 | `글자` |
| 코드 블록 | ``` |

- 어디서나 쓰는 키를 등록할 때 다른 앱이 이미 쓰고 있으면 설정에서 바로 알려 주고 다른 키를 고르게 합니다.
- 휴지통으로 보내는 단축키는 일부러 두지 않았습니다.
- ⌃⌥Space는 쓰지 않습니다(macOS의 입력 소스 전환과 겹침).
