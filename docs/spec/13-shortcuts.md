## 13. 단축키 (화면 7)

설정 사이드바의 단축키 화면 안에 표를 표시합니다. 조합을 13pt 시스템 글꼴과 text-2 색으로 표시합니다. 보조 키는 오른쪽 정렬하며 한 글자 키는 15pt 칸 가운데에 놓습니다. 여러 글자 키는 내용 너비를 확보합니다. 도움말 또는 ⌘/로 같은 창의 단축키 화면을 엽니다. 설정 창은 Esc 또는 ⌘W로 닫습니다. 7단계는 읽기 전용이며 전역 키 변경과 충돌 해결 UI는 후속입니다(D-098).

**어디서나 (다른 앱을 쓰는 중에도)**

| 동작 | 키 |
| --- | --- |
| 빠른 캡처 | ⌃ ⌥ N |
| 떠 있는 노트 모두 숨기기, 다시 보이기 | ⌃ ⌥ H |
| 라이브러리 (노트 더 보기 메뉴에서도 열기) | ⌃ ⌥ L |
| 에이전트에게 요청 | ⌃ ⌥ A |

⌃⌥A를 전역에 등록합니다. 같은 모드에서 다시 누르면 닫고, ⌃⌥N과 번갈아 누르면 열린 막대의 모드를 전환합니다.

**빠른 캡처 바**

| 동작 | 키 |
| --- | --- |
| 추가 | ↵ |
| 새 노트로 띄우기 | ⌘ ↵ |
| 스페이스 바꾸기 | ⇥ |
| 리마인더 직접 고르기 | ⌘ R |
| 닫기 | esc |

**에이전트**

| 동작 | 키 |
| --- | --- |
| 요청을 보내고 대화 열기 | ↵ |
| 노트에서 에이전트 창 열기(그 노트가 대상) | ⌘ J |
| 지우기 확인 팝오버 취소(단계 2) | esc |

설정의 에이전트 묶음에는 Return 전송과 ⌘J를 표시합니다. 노트가 키 창일 때 그 노트의 대화를 엽니다(D-206).

**노트 창**

| 동작 | 키 |
| --- | --- |
| 새 노트 | ⌘ N |
| 노트 찾기 | ⌘ P |
| 더 보기 메뉴 | ⌘ K |
| 다음 노트로 | ⌘ ` |
| 제목 고치기 | ⇧ ⌘ T |
| 항상 위에 고정 켜기, 끄기 | ⇧ ⌘ P |
| 리마인더 설정 | ⌘ R |
| 스페이스 옮기기 | ⇧ ⌘ M |
| 노트 안에서 찾기 | ⌘ F |
| 본문 확대(최대 17pt, 제목과 코드 비례) | ⌘+ 또는 ⌘= |
| 본문 축소(최소 12pt, 제목과 코드 비례) | ⌘− |
| 본문 기본 크기(14pt) | ⌘0 |
| 전체 검색 | ⇧ ⌘ F |
| 창 닫기 (노트는 남음) | ⌘ W |
| 설정 | ⌘ , |
| 이 단축키 표 | ⌘ / |

**노트 찾기**

| 동작 | 키 |
| --- | --- |
| 항목 이동 | ↑ ↓ |
| 열기 | ↵ |
| 닫기 | esc |

**라이브러리**

| 동작 | 키 |
| --- | --- |
| 선택한 줄 열기(휴지통은 복원 후 열기) | ↵ |
| 목록 선택 이동 | ↑ ↓ |
| 컨트롤 사이 이동 | ⇥ / ⇧ ⇥ |

**편집**

| 동작 | 키 |
| --- | --- |
| 날짜 제안 받기 (본문, 제목, 현재 줄에 밑줄 제안이 있을 때; 커서 위치 무관) | ⇥ |
| 날짜 제안만 닫기 (그 줄 내용이 바뀔 때까지) | esc |
| 들여쓰기 (하위 계층으로, 제안이 없을 때) | ⇥ |
| 내어쓰기 / 본문 처음에서 제목으로 | ⇧ ⇥ |
| 투두로 바꾸기 | ⇧ ⌘ 9 |
| 완료 표시 | ⌘ ↵ |
| 줄 위로, 아래로 옮기기 | ⌃ ⌘ ↑ ↓ |
| 접기, 펼치기 | ⌥ ⌘ [ ] |
| 제목 1, 2, 3 | ⌥ ⌘ 1 2 3 |
| 굵게 (선택 영역 또는 다음 입력) | ⌘ B |
| 취소선 | ⇧ ⌘ X |
| 형광펜 (다시 누르면 다음 색) | ⇧ ⌘ H |
| 인라인 코드 | ⌘ E |
| 코드 블록 | ⌥ ⌘ C |
| 링크 | ⌘ L |

**마크다운으로 입력**

| 동작 | 키 |
| --- | --- |
| 제목 1, 2, 3 | # ## ### |
| 글머리표 | - |
| 투두 | [] 또는 [ ] |
| 토글 | > |
| 인용문 | " 또는 \| |
| 굵게 | **글자** |
| 취소선 | ~~글자~~ |
| 형광펜 | ==글자== |
| 인라인 코드 | `글자` |
| 코드 블록 | ``` |

- 어디서나 쓰는 키를 등록할 때 다른 앱이 이미 쓰고 있으면 등록 실패를 기록합니다. 다른 키를 고르는 화면은 후속입니다.
- 휴지통으로 보내는 단축키는 일부러 두지 않았습니다.
- ⌃⌥Space는 쓰지 않습니다(macOS의 입력 소스 전환과 겹침).


- 날짜 제안이 있는 줄을 들여 쓰려면 **esc 뒤 ⇥**를 누릅니다. ⇧⇥는 내어쓰기를 먼저 합니다. 목록이 아닌 첫 줄 맨 앞에 선택 없이 있으면 제목으로 갑니다. 빈 본문도 같습니다(D-103). 날짜 받기는 ⌘Z 한 번으로 원문과 예정 변경을 함께 되돌립니다. 제목에서 제안 없는 Tab이나 Return은 본문으로 갑니다(D-074, D-075).
