## 14. 상태와 상호작용 요약

| 요소 | 상태 | 동작 |
| --- | --- | --- |
| 고정된 노트 | 평소 | 오른쪽 끝에 채운 핀 `text-3`. 예정 칩은 핀 왼쪽. 호버하면 같은 핀이 더 보기 왼쪽으로 이동하고 `text-2`가 된다(D-189) |
| 노트 창 | 마우스가 들어옴 | 제목 `text`, 칩 또는 시계 뒤에 핀, 더 보기, 구분선, 닫기 |
| 제목과 본문 사이 | 평소, 호버, 편집 | 1pt `line` 구분선을 계속 표시 |
| 노트 창 | 포커스 | 설정에서 켰을 때만 본문 커서가 있는 노트에 서식 버튼을 표시 |
| 아이콘 버튼 | 올림 | `hover` 바탕 상자(모서리 `r-control`), 아이콘 `text` |
| 노트 서식 버튼 | 켜짐 | `format-active` 바탕, `text` 아이콘. 올려도 켜짐을 우선 |
| 버튼 | 평소 / 올림 | 흰 바탕과 옅은 테두리 / hover 겹. 되돌리기는 warn 글자 |
| 값 버튼 | 평소 / 올림 | 회색 바탕과 아래 꺾쇠 / hover 바탕 |
| 세그먼트 | 고름 / 다른 칸 올림 | 흰 칸 / hover 바탕 |
| 설정 미리보기, 단축키 값 | 올림 | 반응 없음 |
| 이동 줄 | 올림 | 한 줄 이동 줄은 높이 30pt, 두 줄 이동 줄은 줄 높이에서 위아래 4pt씩 뺀 높이의 hover. 에이전트 행은 52pt 중 44pt를 칠한다. 반경 6pt, 내용 양끝에서 6pt씩 확장 |
| 선택 칸, 칩 | 올림(고르지 않은 것) | `hover` 바탕 |
| 선택 칸, 칩 | 고름 | `selected` 바탕, `text`, 굵기 500. 올려도 변화 없음 |
| 사이드바 줄 | 올림 / 고름 | 테두리 없는 호버와 선택 바탕, 섹션은 `text-3`에 500, 항목은 `text-2`에 400, 선택은 `text`에 500. 높이 28pt, 설정은 행 안쪽 위아래 1pt, 라이브러리는 행 사이 2pt(D-173) |
| 라이브러리 노트 줄 | 평소 / 올림 | 고정된 줄은 평소 오른쪽 끝에 text-3 채운 핀. 선택 여부와 관계없이 올리면 text-2 핀과 더 보기. 버튼에 직접 올리면 text와 hover 바탕. 보관함과 휴지통은 더 보기만 표시(D-260, D-261) |
| 에이전트 쪽 페이지의 줄 | 올림 | `hover`가 줄 전체에 겹침. 줄 끝에 동작이 나타남(D-212~D-215). PR 2에서는 줄 선 요청에 적용 |
| 노트 찾기 줄 | 호버 또는 키보드 선택 | 옅은 회색 바탕과 고정 상태에 맞는 핀. 글자 위치 유지 |
| 라이브러리 목록 | 한 번 클릭 / 더블 클릭, Return | `selected` 선택 / 열기(휴지통은 복원 후 열기). 포커스 링 없음(D-065) |
| 설정의 보기 줄 | 평소 / 끔 / 손잡이 호버 | 손잡이는 늘 보이며 바탕 없이 text-3에서 text-2로 바뀐다. 끄면 이름도 text-3다 |
| 보기와 스페이스 순서 | 끌기 / 놓기 | 잡은 줄은 불투명한 surface와 그림자로 뜨고 같은 구획의 이웃이 실시간으로 비켜난다. 삽입선은 없다. 놓을 때 저장한다. 동작 줄이기에서는 이웃이 즉시 자리를 바꾼다 |
| 스페이스 | 호버 / 펼침 | 왼쪽 아이콘 자리에 꺾쇠, 오른쪽 예약된 칸에 더 보기. 펼친 꺾쇠는 호버가 끝나도 남는다(D-134) |
| 사이드바의 다가오는 일정 | 클릭 / 다시 클릭 / 바깥 클릭 | 누른 줄을 가리키는 상세와 선택 바탕 / 닫기 / 닫고 클릭 전달. 다른 줄을 누르면 이동(D-137) |
| 일정 목록 끝 | 호버 | 오른쪽의 모두 보기, 간단히 보기와 ›가 text-2에서 text로 바뀐다(D-168) |
| 캘린더 메뉴 항목 | 올림 | `selected` 바탕 |
| 값 선택 메뉴 | 고름 | 현재 값 왼쪽에 체크(D-174) |
| 명령 메뉴 | 올림 / 상태 전환 | hover 바탕 / 체크 없이 다음 동작 이름 표시(D-174) |
| 색 칸 | 올림 / 고름 | `text-3` 테두리 / `text` 테두리 |
| 본문 링크 | 올림 | 밑줄 `text` |
| 체크박스 | 올림 | 22pt의 `hover` 바탕, 미완료 선은 `text`, 완료 상자는 채움을 유지. 포인터는 화살표 |
| 토글 꺾쇠, 핀 | 올림 | 기존 반응을 유지 |
| 투두 | 완료 | 상자 채움, 글자 `text-3`에 취소선 |
| 리마인더, 일정 | 예정 / 임박 / 지남 | 5.2, 21 참고. 시각 지정은 15분 전 warn, 굵게, 일정은 캘린더 아이콘 유지 |
| 에이전트 | 연결 필요 | 설정의 사용할 에이전트 메뉴에서 고를 수 없다(11장). 옛 에이전트 목록의 플러그 아이콘은 쓰지 않는다(D-190) |
| 노트 얼굴 | 쉬기 / 일하는 중 / 볼 것 있음 | 쉬면 올릴 때만 보인다. 작업과 답변 대기는 대상 노트에서 올리지 않아도 보이고 고정 핀은 오른쪽 자리를 유지한다. |
| 제안 줄 | 새 제안 / 선택 / 호버 | 줄 끝에 text 점, 열람 시 소거. 호버 때 오른쪽 끝에 버리기와 받기 아이콘. 묶음 머리의 호버는 시각을 모두 받기로 바꾼다. |
| 변경 제안 | 받지 않음 / 받음 / 버림 / 되돌림 | 받지 않은 카드와 연결 줄에 에이전트 색을 쓴다. 받거나 버리면 카드가 사라지고 연결 줄에 상태가 남는다. 대상 충돌은 다시 미리보기로 이어진다. 외부 연동 실패는 로컬 받음을 유지한다. 만든 노트를 이후 고쳤으면 되돌리기를 중지하고 이유를 알린다. |
| 지침 | 직접 편집 / 변경 제안 / 승인 충돌 | 직접 편집은 다음 요청에 반영한다. 제안 상세에는 문서 전체와 변경 기호가 보인다. 충돌 시 기존 문서를 보존하고 다시 미리보기를 제공한다. |
| 대화 줄 | 선택 / 열람 / 답변 | 선택은 한 줄만 강조한다. 열면 열람 시각을 적고 답변을 보낼 때 줄과 사이드바의 warn 점이 함께 사라진다. |
| 화면 구석 단추 | 쉬기 / 일하는 중 / 볼 것 있음 | 한 원의 얼굴만 바뀐다. 단추는 키 창이 될 수 없으며 누르면 대화 창을 연다. |
| 보내기 아이콘 | 글자 없음 / 있음 | `text-3` / `text` |

### 대화 메뉴와 다시 보내기

대화 줄은 호버 때 시각과 점을 더 보기로 바꾼다. 메뉴나 삭제 확인이 열린 동안 줄의 자리를 유지한다. 종료로 멈춘 답에는 이전 진행을 남기고 실패나 연결 대기로 멈춘 줄에는 일괄 동작을 보인다.
