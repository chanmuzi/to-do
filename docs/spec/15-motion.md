## 15. 움직임

| 요소 | 계기 | 움직임 | 시간 | 곡선 |
| --- | --- | --- | --- | --- |
| 호버로 나타나는 것 전부 | 마우스가 들어오고 나감 | 알파 0과 1 사이 | `dur` 180ms | `ease` |
| 순서를 바꾸는 목록 | 끌어 이웃의 절반을 지남 | 이웃이 새 자리로 이동. 동작 줄이기에서는 즉시 이동 | `dur` | `ease` |
| 바탕 효과, 글자색 변화 | 올림, 고름 | 색 전환 | `dur` | `ease` |
| 본문 토글, 제목 토글 | 꺾쇠, 완료 또는 접기 단축키 | 꺾쇠를 90도 회전. 펼칠 때 안쪽 줄을 배치한 뒤 나타내고 접을 때 사라진 뒤 자리를 닫음. 재입력은 현재 프레임에서 반전하고 동작 줄이기는 즉시 전환 | `dur` | `ease` |
| 노트 창 높이 | 토글 접고 폄, 줄 수 변화 | 높이가 내용을 따라감 | `dur` | `ease` |
| 빠른 캡처 바 | 나타나고 사라짐 | `capture-rise`(6)만큼 아래에서 올라오며 알파 0에서 1로. 사라질 때는 반대 | `dur` | `ease` |
| 임박한 리마인더의 종 | 임박 상태인 동안 | 좌우로 흔들림(14도, -12도, 6도) | 1.6초 주기, 뒤 40%에서만 | ease-in-out |
| 에이전트 얼굴 | 창이 보이는 동안 | 쉬는 얼굴은 눈을 감고 뜰 때만, 움직이는 얼굴은 초당 최대 30회 갱신 | 쉬는 얼굴은 `agent-blink`, 작업은 상태별 주기 | 상태별 |
| 입력 커서 | 포커스 | 시스템 기본 깜빡임 | | |
| 기본 이미지 | 항상 | 프레임 바꿈 | `assets/pixel/manifest.json` | 단계 |

"동작 줄이기"가 켜져 있으면 에이전트 얼굴, 종, 기본 이미지의 움직임을 멈추고(첫 프레임), 호버 전환은 바로 바꿉니다.
