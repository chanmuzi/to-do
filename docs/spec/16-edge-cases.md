## 16. 가장자리 경우

- **빈 노트**: 본문에 자리 글자를 넣지 않습니다. 커서만 있습니다.
- **제목 없음**: 상단 줄, 노트 찾기에서 "제목 없음"을 흐리게. 라이브러리 줄에서는 본문 첫머리가 제목 자리에 올라오지 않습니다(제목과 본문은 별개).
- **긴 제목**: 한 줄, 말줄임표. 좁은 노트(260)에서도 리마인더와 핀이 밀려나지 않게 제목이 먼저 줄어듭니다.
- **긴 본문**: 창 높이가 한도에 닿으면 스크롤. 스크롤 막대는 스크롤할 때만 보입니다.
- **긴 한 줄(주소, 코드)**: 본문과 코드 블록 모두 줄바꿈합니다. 가로 스크롤을 만들지 않습니다.
- **노트가 많을 때**: 라이브러리와 노트 찾기는 스크롤. 노트 찾기는 최근에 연 노트를 여덟 줄까지만 보이고 나머지는 검색으로 찾습니다(가정).
- **검색 결과 없음**: 노트 찾기는 "새 노트 만들기" 줄만. 라이브러리 목록은 빈 채로 둡니다.
- **리마인더가 지남**: 지남 상태로 남고, 사용자가 리마인더를 지우거나 다시 정할 때까지 유지합니다.
- **에이전트가 하나도 연결되지 않음**: 입력 칸은 그대로 두고, 보내면 연결 안내를 엽니다.
- **에이전트 응답 실패**: 에이전트 자리에 한 줄로 이유와 "다시 시도" 링크. 빨간 상자를 쓰지 않습니다.
- **큰 이미지나 GIF**: 아이콘으로 올릴 때 긴 변 64px로 줄여 저장합니다. 1MB가 넘는 GIF는 받지 않고 그 자리에 한 줄로 이유를 보입니다(가정).
- **투명도를 낮췄을 때**: 30%에서도 글자가 읽히도록 배경 흐림을 켜 두기를 권합니다. 흐림을 끄고 투명도가 60% 아래면 글자 뒤가 비쳐 읽기 어렵습니다. 막지는 않습니다.
- **다크 모드**: 색 토큰만 바뀝니다. 팔레트는 같은 값을 쓰고 섞는 대상(`surface`)이 달라져 어두운 색이 됩니다.
- **화면이 여러 개**: 노트는 놓인 화면을 기억합니다. 그 화면이 없어지면 주 화면의 같은 상대 위치로 옮깁니다.
- **다른 앱에서 Float 창을 누름**. 노트, 설정, 캡처, 찾기, 대화 창, 제안 카드, 확인 팝오버와 알림의 보기에서는 누른 대상이 포커스를 정합니다. 라이브러리를 올리지 않기로 한 판단은 비활성으로 돌아갈 때까지 이어 씁니다. 알림 사이에 비활성이 끼면 원래 로컬 누름부터 0.5초 이내이고 더 최근 키 누름이 없을 때만 그 누름을 다시 씁니다(D-187, D-244).
- **포인터가 노트 위인 앱 전환**: 위치만으로는 클릭으로 판단하지 않습니다. 최근 0.5초 안의 왼쪽 누름과 포인터 아래의 Float 창을 함께 봅니다. 더 최근 키 누름이 있으면 앞서 기록한 누름과 포인터 추정을 쓰지 않습니다. Dock과 Spotlight의 재열기는 라이브러리를 앞으로 가져옵니다(D-101, D-187).
