## 17. 접근성

- **아이콘 버튼의 이름**(VoiceOver): 노트 찾기, 더 보기, 새 노트, 휴지통으로 보내기, 창 닫기, 항상 위에 고정(켜짐과 꺼짐을 값으로), AI 패널, 설정, 복사, 보내기, 닫기. 호버로만 보이는 버튼도 VoiceOver와 키보드로는 항상 닿아야 합니다.
- **키보드만으로**: 노트의 모든 동작은 더 보기 메뉴(⌘K)에서 할 수 있어야 합니다. 팝오버와 패널은 열리면 첫 입력 칸에 포커스가 가고, esc로 닫히며, 닫히면 열었던 곳으로 포커스가 돌아갑니다.
- **사이드바 순서**: 설정 손잡이는 ‘순서 바꾸기’와 보기 이름을 읽는다. 설정 손잡이와 사이드바 보기, 스페이스 이름에 포커스한 뒤 Option과 위쪽 또는 아래쪽 화살표로 옮긴다. VoiceOver 동작 메뉴에는 가능한 위로, 아래로 동작만 둔다. 오른쪽 클릭 메뉴의 경계 명령은 비활성이다.
- **색에만 기대지 않기**: 임박은 색과 함께 종 아이콘과 굵기로도 표시합니다. 노트 색은 팔레트 이름을 접근성 이름으로 붙입니다.
- **대비**: `text-3`(라이트 #8F8F8F)은 흰 바탕에서 약 3.2:1이라 작은 글자 기준(4.5:1)에 못 미칩니다. 보조 정보에만 쓰고 있지만, 시스템의 "대비 증가"가 켜져 있으면 `text-3`를 `text-2`로, `line`을 `outline`으로 바꿉니다.
- **동작 줄이기**: 15장 참고.
- **글자 크기**: 본문 크기 설정(12부터 16)을 따르고, 상단 줄과 정보 글자는 고정입니다.

### 대화 메뉴와 다시 보내기

대화 더 보기는 이름이 있는 버튼이다. 명령의 이름과 비활성 상태를 전달하고 이름 편집은 공용 한 줄 입력칸을 쓴다. 삭제 확인은 Esc와 바깥 누름으로 닫히며 Return에 기본 동작을 지정하지 않는다. 대기열의 두 버튼은 폭이 좁아져도 이름과 순서를 유지한다.

마지막 줄 끝에 표시 공간이 있는 동안 대화 입력 칸의 모델 단추는 포인터를 올리기 전에도 접근성 이름으로 모델과 강도를 제공한다. 키보드 초점을 받으면 보이고 Space 또는 Return으로 메뉴를 연다.
